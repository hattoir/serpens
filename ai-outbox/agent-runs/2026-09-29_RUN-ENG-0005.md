## Key results

- 角度合計: 145° を維持。速さは 145〜180° で変わらず、旋回半径が縮むだけ（145° で最悪 185 mm、仮置きの要件 600 mm の 31%）。180° 以上は C 字の口が袋小路
- 暫定しきい値（PROVISIONAL）: 手・指 5.7 N、首 5.0 N（乳児の気道 = Walker 2010）、胸 5.7 N、腕 6.1 N、顔 2.7 N、衝撃係数 1.0
- **トルクだけではしきい値を満たせない**（0.45 N·m でも節の中点で 9.5 N）→ 幾何で守る要求（5〜12 mm の隙間なし、袋小路なし）
- 機械式リミッター: 窓 0.7〜1.0 N·m。**0.6 は個体差 −30% で不要な滑りが 15%**。歯車の破断トルクが最重要の未知
- Head Yaw（USER-DEC-SERPENS-0004）: 最悪の巻ける角は胴 145° + 頭。±30° で 175°（余裕 5°）、±45° で 190°（袋小路）。暫定 ±30°

## Rejected / corrected

- 初回の結果表の説明文が古い（「頭ヨーを足す」）まま残っていたのを、頭ヨーを鎖に含める実装に合わせて直した
