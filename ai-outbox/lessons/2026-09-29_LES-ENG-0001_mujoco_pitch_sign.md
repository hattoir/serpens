# LES-ENG-0001 — 物理モデルの軸の符号は、別のモデルと突き合わせるテストで守る

- Date: 2026-09-29 / Area: Simulation / Label: SOFTWARE_VERIFIED（修正とテスト）

## 何が起きたか

MuJoCo モデルの pitch 軸が、運動学（`serpens/motion/kinematics.py`: + で頭が上がる）と逆向きだった。
EX-1 の home（J7 = +8°、「頭をわずかに浮かせる」）は、MuJoCo の中では頭を床へ押し込んでいた。
その状態のまま、「サーボゲインで前進量が ±45% 変わる」という結論と、旋回のテストが作られていた。
旋回のテストは γ の向きを見ずに絶対値で比べていたので、左旋回の指令で右へ回っても通っていた。

## 教訓

- 軸の符号・単位・座標の向きは、**別の実装との一致をテストで固定する**（今回 `test_positive_pitch_raises_the_head` を追加した）
- 旋回のような向きのある量は、**符号まで検査する**。絶対値の比較は誤りを隠す
- sim の結論を docs に書くときは、それを生んだモデルの版（指紋）も残す。モデルを直したら、その結論を見直す
