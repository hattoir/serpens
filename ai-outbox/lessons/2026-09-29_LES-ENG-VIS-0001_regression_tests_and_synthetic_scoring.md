# LES-ENG-VIS-0001 — 回帰試験は「修正を外すと落ちる」まで確かめる／合成の採点を疑う

- Date: 2026-09-29 / Branch: `agent/engineering-vision-sim` / Context: H2 合成視覚（VIS-0002〜0006）

## 起きたこと
1. **修正を外しても通る回帰試験を 1 度書いた**（影でつないだ小片の保護）。種 100/101 では、そもそも不具合が再現しなかった。
   修正を外して試験を回す手順を毎回入れていたので気づけた。**掃引で実際に落ちた試行（対象・種）を、そのまま試験に固定した**。
2. **検出の失敗と思ったものの 3 つが、採点の側の誤りだった**:
   - カメラの姿勢がずれると検出率が 0.15 に落ちた → 床へ戻した位置のずれを「見逃し」と数えていた（画像の上で重なりを見るように直した）
   - 隣の物（おもちゃ）の誤報 0.67〜0.89 → おもちゃ自身の検出を誤報に数えていた
   - 位置の誤差「約 6mm」→ 候補の位置は手前の縁、真値は中心（半径ぶんの差）
3. **合成の側の誤り**: カーペットの模様の倍率が 0 以下になり、真っ黒な画素が「影」を作っていた。描画の雑音に種が無く、試行が再現しなかった。

## 教訓
- 回帰試験を書いたら、**修正を外して落ちること**を毎回確かめる（通るなら、その試験は何も守っていない）
- 合成の結果が大きく崩れたら、検出を直す前に**採点と描画を疑う**（何を正解とし、何を数えているか）
- 乱数は種を持たせ、失敗した試行を後から同じ条件で再現できるようにする
- 合成の床の模様に検出を合わせ込まない。残った誤報（暗い繊維での線の途切れ）は実写（HA-04）で合わせる
