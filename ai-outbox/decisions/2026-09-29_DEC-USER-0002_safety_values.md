# DEC-USER-0002 — 対象年齢・接触安全のしきい値・角度合計の上限・機械式トルクリミッター

- Date: 2026-09-29 / Decided by: **User**（chat で指示）/ Recorded by: Engineering Agent
- Responds to: OQ-0003, OQ-0006, OQ-0112, OQ-0113

## Decision

1. **対象年齢（OQ-0003）**: Primary target = **3 歳未満**（小物の誤飲）。Safety design envelope = **6 歳以下**（ボタン電池等）。
   機械設計は envelope 内の**小さい身体寸法側**を保守的条件にする。**首径・手首径は年齢から推測しない**。信頼できる anthropometric source を探してモデル化する
2. **接触安全のしきい値（OQ-0006）**: User は数値を決めない。Engineering Agent が、規格・子どもの anthropometry・生体力学の文献・保守的なシミュレーション・H1 / H2 以降の実測から**暫定値を導く**。
   単一資料の成人値を子どもへそのまま転用しない。確定まで **PROVISIONAL / SAFETY_UNVERIFIED**。候補が複数あれば安全側を baseline にして自律的に探索する
3. **角度合計の上限（OQ-0112）**: 暫定 Software Safety Limit = **145°**（最終値ではない）。145 / 150 / 160 / 170 / 180° を掃引し、
   locomotion・reachability・巻き付きの幾何・首 / 胸の囲い込み・挟み込み・ケーブル・機械の干渉を比べる。安全と性能の evidence が得られた場合だけ 145° から上げる提案をしてよい
4. **機械式トルクリミッター（OQ-0113）**: 「採用候補」ではなく**設計に含めて検証する Safety Layer**。滑りトルクは未確定。
   ソフトの上限 約 0.45 N·m + 機械のリミッター（下限の候補 約 0.6 N·m）の**二重の安全層**として、0.5 / 0.6 / 0.7 / 0.8 / 1.0 N·m（必要なら拡張）を掃引。
   評価: 通常の移動・頭の保持・障害物越え・子どもが引く・指の挟み込み・巻き付き / 接触・歯車の保護・不要な滑り・故障モード。H1 の実測後に最終候補を更新
5. **自律実行**: これらの安全値について逐一 User に質問して止まらない。安全に可逆な範囲では、資料調査 → パラメータ化 → シミュレーション → 最悪条件の探索 → しきい値の提案 → 回帰テスト を繰り返す。
   **Human Approval が要るのは、実機に適用する最終の安全しきい値を緩和する場合だけ**
6. **H0**: 実機の最優先は H0 のまま。実測待ちで止まらず、未測定の摩擦の範囲を掃引して Head Yaw / Body Yaw / Wheel Belly の判定境界を更新し続ける
