# H1 — C044 1 関節の実測計画（**未実施。サーボは未購入**）

対象: FEETECH ST3215-C044（7.4V / 1:191）×1。User 指示（2026-09-29）で H1 は C044 で行う。
電源・ヒューズ・電池の設計は、ここの実測が出るまで確定しない。

## 0. 始める前に決めること（**Human Approval が要る**）

### 0.1 トルク制限レジスタの比を作り直す（安全）

現在 `config/robot.yaml` の `software_torque_limit_ratio: 0.287` は、**stale / source-unverified な C044 のストール値 16 kgf·cm（1.569 N·m）**から
0.450 / 1.569 で出した値。現行の Seeed / Feetech 資料の C044 は **ストール 27.4 kgf·cm（2.687 N·m）/ 定格 9 kgf·cm**。
レジスタ比がストール基準なら、0.287 を書くと **約 0.77 N·m** まで出る（意図した 0.45 N·m の約 1.7 倍）。

提案: H1 の最初の通電までに、比を **0.450 / 2.687 = 0.167** にする（強くする方向。緩めない）。
実測したストールトルクで、あらためて比を作り直す。**config の値はまだ変えていない**（安全に関わる設定なので承認を待つ）。

### 0.2 電源

電流制限付きの安定化電源（あれば OQ-0104）で **7.4V、電流制限 3A から**。無ければ INA226 と、ヒューズを入れた 2S 電源の案を別に作る（未設計）。
**12V を入れない。**`tools/servo_setup.py` のメニュー 3 で、最高入力電圧の設定を最初に確かめる。

## 1. 治具

- サーボを固定する台（3D 印刷。取付穴は実物をノギスで測ってから作る。推測で製造確定しない）
- 出力軸にアーム（100 mm）を付けて、先端におもりを下げる／キッチンスケールを押す（トルク = 力 × 腕の長さ）
- 指を入れない。可動範囲の外へ出たらすぐ電源を切れるスイッチを手元に置く

## 2. 測ること（1 項目ずつ。記録は `h1_joint_template.csv`）

| # | 項目 | 方法 | 何が決まる |
|---|---|---|---|
| 1 | 寸法・質量 | ノギス（本体・ホーン・取付穴・軸高さ）、はかり | CAD の REFERENCE_ONLY を置き換える |
| 2 | 待機電流・保持電流 | 無負荷・位置保持で 1 分 | 電源の待機分 |
| 3 | 無負荷速度 | 位置指令 ±50° の往復を telemetry（位置）で測る | 歩容の上限（0.5 Hz × 40° で最大 約 126°/s が要る） |
| 4 | トルクと電流の関係 | 腕の先に 0〜数段のおもり。各段で電流・load 値・位置のずれ | load 値の意味（符号ビット bit10 の仮説も）、電流 → トルクの換算 |
| 5 | ストールトルク・ストール電流 | 腕を止めて短時間（数秒以内）。温度を見ながら | ヒューズ・配線・コネクタ・電池の最大電流 |
| 6 | 温度上昇 | 歩容相当の負荷を 10 分 | 60 ℃ 停止までの余裕 |
| 7 | トルク制限レジスタの効き | 比 0.167 のときの実際の最大トルク | `software_torque_limit` を実測で確かめる |
| 8 | 停止挙動 | 電源断・トルク OFF・通信断のそれぞれで、腕がどう落ちるか・どれだけで止まるか | バックドライブのしやすさ、停止時間（ELECTRICAL_SAFETY_GATE の real_stop_time） |
| 9 | telemetry | 位置・速度・load・電圧・温度の読み出し周期、SYNC READ の対否（メニュー 7） | ESP32 側の監視周期 |

## 3. ラベル

測った値は、日付・条件・測定器を付けて **HARDWARE_VERIFIED（この個体・この条件に限る）**。
別の個体・別の電圧へ流用しない。ELECTRICAL_SAFETY_GATE の項目は、証拠を書くまで COMPLETE にしない。
