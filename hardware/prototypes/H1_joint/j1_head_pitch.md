## 2. 床接触の較正の手順（`simulation/hardware_gaps/HG-H1_actuator/j1_floor_contact.py` が同じ手順の参照実装）

**前提（Design の配置）: J1 = 0° で、足の帯の底と横スキッドの底を同一面にする**（スキッドが c₀ 下へ出る、ではなく、**スキッドが床に触れたとき、口の前縁の高さは 0**。ASSUMED。Design が CAD の配置で確認する）。

1. **準備**: サーボの設定を確認（最高入力電圧 14 番地、トルク制限 48 番地、位置補正 31 番地。H1 の #1）。J1-1 で 不感帯 D、J1-4 で τ_move を測ってある。
2. **上限を τ_move に**（動かせる最小の値。既定の 0.449 N·m ではない）。
3. **窓の上（+1° ≒ +11 ステップ）から始める。必ず上から近づく**（バックラッシ・不感帯の側を揃える）。
4. **1 ステップずつ目標を下げ、50 ms 待つ**。位置の読み値が目標に追従しなくなったら（**目標 − 読み値 ≥ D + 2 ステップが 3 回続く**。D + 2 未満にすると、不感帯だけで「接触」と誤判定する）、**床に触れた**と判定する。**エンコーダがモーター側なら（J1-2）、位置ではなく 負荷（60 番地）・電流（69 番地）が上限に張り付いたことで判定する**。
5. **押し込みを戻す**: 目標を現在の読み値にする（上限で床を押している分を抜く）。読み値を q_contact として記録（`present_position`、ステップ）。
6. **c の分だけ上げる**: n_c = round(c / 0.0832 mm)（c = 0.1 → 1 ステップ、0.3 → 4、1.0 → 12。前縁 54.2 mm、4096/回転）。**上げる向きは反転**なので、不感帯・バックラッシが効く → 上げたあと読み値を確かめ、q_contact + n_c に届いていなければ 1 ステップずつ足す（最大 6 回）。
7. **作業中の上限 τ_hold（≲ 0.02 N·m、レジスタ 8）に落とす**。以後、J1 は 0° 指令。
8. **記録**: q_contact、q_final、n_c、床の種類、温度、電圧（`j1_head_pitch_template.csv` の行）。

**判定（J1-1〜J1-5 の結果でどう決まるか）** — 1 ステップ = 口の前縁 0.083 mm。

| 不感帯 D + バックラッシ B（エンコーダが出力側ならバックラッシは読み値で補正できるので D、モーター側なら D + B） | 結論 |
|---|---|
| ≤ 1 ステップ（0.08 mm）| c = 0.1 mm を J1 で守れる。上の手順のまま |
| 1〜4 ステップ（0.08〜0.33 mm）| 上から近づく一方向の手順で、c は ≥ 0.3 mm で守れる。c = 0.1 は誤差が同程度（**スキッドの底の高さ・足の帯の平らさで決める**） |
| > 4 ステップ | J1 では c を守れない。**c は Design の機械（スキッドの底の高さ、足の帯）で決め、J1 は 0° に「柔らかく押しつける」だけ**（押す力は τ_hold で頭の重さ以下に） |

**「J1 は使わない」代案（B）**: 較正用に τ_move の高い上限を使うと押す力が暫定しきい値に近づく場合（J1-4 で τ_move の力 > 2.8 N）、**床接触の較正をやめ**、スキッド（機械）で高さを決めて、J1 の作業中の位置は 0° 固定（上限 τ_hold）にする。この場合、J1 の役割は「頭を床に押し付けない」だけ。

## 3. 合否（提案。User が決めるまで安全の合否は出さない）

- J1-3: 実際の押す力（サーボ分）が、頭の重さ（約 1 N）以下、かつ 暫定しきい値 5.7 N の半分（2.8 N）以下
- J1-4: τ_move の押す力が 2.8 N 以下
- J1-5: q_contact の標準偏差 ≤ 1 ステップ、c = 0.1 mm を狙って 前縁の高さの誤差が ±0.1 mm 以内（30 回中 27 回以上）
- 上の判定が満たされない場合、**結果が悪くても後付けの調整はしない**。結論（J1 で c を守れない）をそのまま書く

### 5.1 符号（**J1-0: 実機の符号の確認。ストッパーの窓を切る前に、必ず先に**）

- **Engineering の符号: + = 頭を上げる**（`config/robot.yaml` の J7 `direction: 1`、`serpens/motion/poses.py`（J7 = 首ピッチ = 持ち上げ・うなずき、人を見るときは 55〜65° = 上げる側）、MuJoCo の pitch 軸の符号の修正「+ で頭が上がる」、口の前縁が +0.95 mm/° 上がる）。**Design の CAD の姿勢変換は + = 頭を下げる**（Design の `j1_sign_correction_2026-09-30.md`）。Design は θ_E = −θ_CAD で読み替え済み。**Engineering 側の符号は、コード・設定で + = 上げに一貫しているが、実機のサーボ（取付の向き・ホーン）での確認は未実施（HARDWARE_VERIFIED ではない）**。
