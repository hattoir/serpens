# HG-S1 — 実機試験の計画（接触安全）

**人（子ども）を使った試験はしない。** 力は治具・ばね秤・人形の部位の模型で測る。

## 先に User に決めてもらうこと（試験の前提）

| # | 決めること | なぜ |
|---|---|---|
| U1 | 対象の子どもの年齢（OQ-0003） | 体の太さ（首・手首）と力の幅が決まる。機械ストッパーの角度の上限が決まる |
| U2 | 安全のしきい値: 押し付け力・挟み込み力・衝撃力（OQ-0006） | いまは数字を並べただけで合否を出していない |
| U3 | 横関節の角度合計の上限（145〜180° の窓のどこか） | ファームの上限の強制に入れる値 |

## 測ること（H1 の 1 関節の治具を流用）

| # | 測定 | 確定すること |
|---|---|---|
| S1 | 機械ストッパーの実角度（関節を手で押し込み、止まる角を読む。外装込み） | 内径 = 首が入るか（±52° 前後以下か） |
| S2 | 通電・上限 0.167 で、節の中点と関節から 20 mm で押し付ける力（ばね秤） | 押し付け力の表を実測で置き換える |
| S3 | 脱力時のバックドライブトルク | 挟まれたとき、脱力で抜けるか |
| S4 | 手で曲げたときの抵抗と、歯車の異音・滑り（上限を超えて回されるとき） | 歯車に外力が掛かるときの挙動。破断トルクはメーカー資料で確認（**破壊試験は予備の個体で、User 承認後**） |
| S5 | 首 J1 の機械ストッパー（CAD の G1 試験台で頭の質量を模した重りを吊る） | 持ち上げたときに J1 が荷重を受けないか |

## この計画で確定しないこと

子どもの実際の行動、長期の摩耗、外装の破損と破片の出方。これらは人の観察（HUMAN_EVALUATED）と耐久試験が要る。
