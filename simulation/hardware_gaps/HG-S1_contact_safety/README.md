# HG-S1 接触安全（SAFETY GAP）

**何が実測不足か**: 子どもとの接触（巻き付き・圧迫・引っ張り・曲げ・踏みつけ・持ち上げ）で実際に掛かる力、歯車の破断トルク、脱力時のバックドライブ、
子どもの体の太さと力（対象年齢は 3 歳未満 / envelope 6 歳以下に決定。2 歳未満の寸法は出典なし）、安全のしきい値（暫定値を導出済み・未確認あり）。

**方針**: 危険側に倒した解析（SAFETY_WORST_CASE_MODEL）。しきい値は User が決めず、規格・子どもの計測値から**導いた暫定値**（`../safety_thresholds.yaml`、DEC-USER-0002 §2）を使う。
安全に関わる設定は、より厳しい方向なら自律的に変えてよいが、**緩める変更は User の承認が要る**（DEC-USER-0002 §5）。

## 主な読み（`decision_boundary.md`）

1. **横関節の角度合計の上限: 暫定 145° を採用**（DEC-USER-0002）。歩容は旋回込みで最大 142°（HG-S2 で 145〜180° を掃引し、上げる evidence は無い）
2. ソフトの可動域 ±50°・関節部の幅 92 mm なら、最大に曲げた輪の内径は 112 mm。子どもの首（直径 63.7〜88.5 mm、Snyder 1977 の実測）・手首（29〜43 mm）は**輪の中で緩い**
3. 外力で機械の可動域 ±55° まで押し込まれると内径は 90 mm で、首の大きい側（88.5 mm）との余裕は 1.5 mm。**機械ストッパーは ±52° 前後以下**が要る（±53° で余裕 5 mm、幅 92 mm）
4. **暫定の接触しきい値（`safety_thresholds.yaml`、PROVISIONAL / SAFETY_UNVERIFIED）は、手・指 5.7 N、首 5.0 N（乳児の気道 = Walker 2010）、胸 5.7 N、腕 6.1 N、顔 2.7 N**（子どもの痛み閾値で成人の規格値を縮めた安全側）。
   関節のトルクだけでは、どの層でもこれを満たせない（0.45 N·m でも節の中点で 9.5 N、20 mm で 22 N）→ **幾何で守る**（5〜12 mm の隙間を作らない、閉じた開口・袋小路を作らない）と、力を逃がす柔らかい外装
5. 押し付ける力は、トルク上限が効いていれば節の中点で 6〜13 N、関節の近く 20 mm で 14〜32 N。上限が効かないと 63〜150 N
6. 引く・曲げる外力はトルク上限を 1 桁以上超える（子どもの引く力は CPSC 実測で最大 238 N）→ サーボは回されるが、**歯車に外力が掛かる**（破断トルクは未知。破片は誤飲物になる）→ 機械式リミッター（HG-S3）
7. 頭を持って持ち上げると首 J1 に 2〜3.5 N·m → J1 は機械ストッパーで受ける設計が要る
8. 子どもの体の寸法は **2 歳未満（Primary target を含む）に出典が無い**（Snyder 1977 に 2 歳未満は 3 件）。空白は `child_anthropometry.yaml` の `gaps`
