# HG-S1 接触安全（SAFETY GAP）

**何が実測不足か**: 子どもとの接触（巻き付き・圧迫・引っ張り・曲げ・踏みつけ・持ち上げ）で実際に掛かる力、歯車の破断トルク、脱力時のバックドライブ、
子どもの体の太さと力（対象年齢も未決定 = OQ-0003）、安全のしきい値（OQ-0006）。

**方針**: 危険側に倒した解析（SAFETY_WORST_CASE_MODEL）。しきい値は推測で入れず、**力と角度の数字**を出して User の安全判断の材料にする。
安全に関わる設定（可動域・角度合計の上限）は、この結果だけで config を変えない（User 承認）。

## 主な読み（`decision_boundary.md`）

1. **横関節の角度合計の上限の窓は 約 145°〜180°**。旋回を含めて歩容に要る「連続した関節の角度の和」は最大 142°（5 構成とも）。
   180° 未満に置けば、体が手首・首を囲い込めない。現在の数値は未設定（PRODUCT.md §4 の要件）
2. ソフトの可動域 ±50°・関節部の幅 92 mm なら、最大に曲げた輪の内径は 112 mm。子どもの首（70〜90 mm の仮定）・手首は**輪の中で緩い**
3. 外力で機械の可動域 ±55° まで押し込まれると内径は 90 mm = 首の上限と同じ（余裕 0）。**機械ストッパーは ±52° 前後以下**が要る
4. 押し付ける力は、トルク上限が効いていれば節の中点で 6〜13 N、関節の近く 20 mm で 14〜32 N。上限が効かないと 63〜150 N
5. 引く・曲げる外力は上限を 1 桁以上超える → サーボは回されるが、**歯車に外力が掛かる**（破断トルクは未知。破片は誤飲物になる）
6. 頭を持って持ち上げると首 J1 に 2〜3.5 N·m → J1 は機械ストッパーで受ける設計が要る
7. 機械式トルクリミッターの滑りトルクは 約 0.6 N·m 以上（歩容の必要トルク × 余裕）、上限は歯車の破断トルクと力のしきい値しだい
