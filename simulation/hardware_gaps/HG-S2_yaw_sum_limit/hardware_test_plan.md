# HG-S2 — 実機試験の計画（角度合計の上限）

上限そのものは幾何と論理なので、実機で確かめるのは「実際にその形が作られない」ことと、余裕。

| # | 測定 | 方法 | 確定すること |
|---|---|---|---|
| Y1 | 上限の強制 | 実機（1〜2 リンク、H3）で、上限を超える DRIVE / BODY / POSE を送り、NACK と縮小が働くことを確認（サーボの位置を読む） | 3 層（指令検査・最後の砦・ServoBus）が実機で効くこと |
| Y2 | 巻ける角の実測 | 歩容と旋回を最大にして動画（真上）を撮り、連続した関節の角度の和と C 字の口の開きを読む | 145° の余裕、袋小路にならないこと |
| Y3 | 実際の輪の内径 | 外装込みで最大に曲げ、内径と口の幅を測る | HG-S1 の内径（112 / 144 mm）を置き換える |
| Y4 | 首・手首の模型を C 字の内側に入れて引く | 首の模型（直径 64〜89 mm の丸棒）を入れ、口から外へ出せるか（引っかからないか）を確認 | 袋小路が無いこと。**人での試験はしない** |

合否（提案）: Y1 で超える指令が必ず縮む / 拒否される、Y2 で角度の和が 145° を超えない、Y4 で丸棒が引っかからず出る。
145° を上げる提案は、H0 の実測で摩擦の比が判明し、旋回半径が要件（OQ-0109）を満たさないと分かった場合に限る。
