# HG-S2 胴体ヨーの角度合計の上限（SAFETY GAP + MODEL GAP）

DEC-USER-0002 §3: 暫定 **145°**（PROVISIONAL / SAFETY_UNVERIFIED）を採用。145 / 150 / 160 / 170 / 180° を掃引し、
移動・届く範囲・巻き付きの幾何・首や胸の囲い込み・挟み込み・ケーブル・機械の干渉を比べた。**安全と性能の evidence が揃った場合だけ 145° から上げる提案をしてよい。**

## 実装（2026-09-29）

上限は `link.limits.yaw_sum_deg = 145`。対象は yaw の鎖（胴体ヨー + 頭ヨー。首 pitch によらず同じ平面とみなす = 安全側）で、
「連続した関節の角度の和」の最大が上限を超えない。**3 か所で守る**（どれか 1 つが壊れても残る）:

| 層 | 場所 | 超えたとき |
|---|---|---|
| 機体側の指令検査 | `DeviceMotion.drive_ok` / `body_ok`（ファームは `driveOk` / `handleMotion`） | NACK（OUT_OF_RANGE） |
| 機体側の最後の砦 | `DeviceMotion.output` / `set_pose`（ファームは `fitYawSum`） | 鎖を同じ比で縮める |
| サーボバス（PC 直結の経路を含む最下層） | `ServoBus.sync_set_goals` → `fit_yaw_sum` | この指令の yaw 軸だけを縮める（前の姿勢と合わせて判定） |

## 結論（`decision_boundary.md`）

- **145° から上げる evidence は無い → 145° を維持する。** 直進の速さは 145〜180° で変わらない（最も速い直進の歩容でも角度合計は 121° 以下）。
  上げて得られるのは旋回半径の短縮（最大 −152 mm）だけで、145° の時点で最悪 185 mm と、要件の仮置き 600 mm（OQ-0109）の 31%
- 180° 以上は C 字の口が内径より狭くなり（袋小路）、首・手首が引っかかる。150〜170° は口が開いているが、180° に近づくほど余裕が減る
- 1 関節の可動域は上限で変わらないので、ケーブル（HG-C1）と関節の干渉（R03 の 64.8°）は同じ
- 前提: 摩擦の比が判定境界より高いこと。比が低いと分かったら、不足するのは旋回ではなく**前進**で、角度合計の上限では解決しない（6 本目のモーターの用途の問題、HG-H0）

## 副作用（承認した上限に合わせて直したもの）

- 休憩姿勢 `poses.rest_arc`: 合計 240° → **135°**（= 145° − 呼吸の振幅の和 10°）。同じ形のまま開いた。
  `tests/test_gait_poses.py::test_rest_arc_has_no_self_intersection` は「合計 200° 以上」から「120° 以上で、呼吸を最大に足しても上限以下」に変えた（安全側）
- `legacy_poses`（旧とぐろ 329° など）は上限を超えるが、シミュレーション専用で機体へは送らない
