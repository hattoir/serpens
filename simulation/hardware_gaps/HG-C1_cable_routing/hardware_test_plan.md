# HG-C1 — 実機試験の計画（関節渡りのケーブル）

H1 の 1 関節（C044）と、H3 の 1〜2 リンクで行う。

| # | 測定 | 方法 | 確定すること |
|---|---|---|---|
| C1 | 束の実寸と許容曲げ半径 | 実際に通す線（サーボバス・カメラ電源・I2C・LED）を束ね、ノギスで太さ。丸棒に巻いて被覆の白化・ねじれが出ない最小の半径 | `min_bend_radius_mm` を置き換える。R10 か R5 か |
| C2 | 外装の中の空き | CAD（FW03/FW04）で、yaw 軸の上（ホーン側）と下に取れる空きを測る（**CAD 作業**） | `bow_space_mm` を置き換える |
| C3 | 軸の上を通す試作 | a ≈ 25 mm、高さの差 20 mm の仮アンカーで 1 関節に通し、±50° を往復 | 実際のたわみの形と、擦れる場所 |
| C4 | 耐久 | ±50° 往復 1000 回（0.5 Hz で約 33 分）。被覆の擦れ・断線・コネクタの引っ張り | 可動域を「ケーブル込み」で確定する材料（`verified_with_cable`） |

合否（提案）: C4 で被覆の擦れ・導通の変化が無い → `joint_limit_policy.verified_with_cable` を true にする材料（**User 承認と記録が要る**）。
