# HG-C1 関節渡りのケーブル（MODEL GAP + PARAMETER GAP）

**何が実測不足か**: ケーブル束の太さ・許容曲げ半径・剛性（束の中身も未確定 = `Serpens_配線設計メモ_20260927.md`）、外装の中でたわみを逃がせる空き。
**なぜ効くか**: 可動域（±50 / 55°）が「ケーブル込み」で確定していない（`joint_limit_policy.verified_with_cable: false`）。R04 の上ループは外装から突出、R05 横通しは未成立。

User 指示（2026-09-29）の「Fixed Zone と Moving Zone を分ける」に沿い、ここでは **Moving Zone（関節渡り）だけ**を扱う。固定区間は FW04 のガイド（CAD）。

## モデル（CABLE_GEOMETRY_SIM）

平面図で yaw 軸を原点に、固定側アンカー A = (−a, e)、可動側アンカー B = (b, e) を関節角で回す。自由長は一定（最大の弦 + 余長）。
余りは両端固定の座屈形のたわみになるとして、たわみの大きさと最小曲げ半径を出す。両端の向きのずれによる曲げも見る。
**剛性・摩擦・ねじれ・束の太さは入れていない。** FW04 の仮アンカーの弦（23.509〜75.424 mm）は再現する（run.py が照合を出す）。

## 主な読み（`decision_boundary.md`）

1. **横通し（yaw 軸から横に 28.5 mm）は長さの変化が 36 mm 以上**で、どの曲げ半径・空きでも成立しない
2. **関節渡りは yaw 軸の上か下（平面図で軸から 10 mm 以内）を通す**のが成立域。軸を通れば、回っても弦の変化は 3〜12 mm
3. D5 束・R10 のままだと、空き 12 mm で成立するのは 1 点だけ（a ≈ 25 mm、高さの差 20 mm）。**細い線に分ける（R5）か、軸の上に 20 mm の空きを取る**と窓が広がる
