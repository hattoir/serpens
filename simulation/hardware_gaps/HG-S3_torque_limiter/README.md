# HG-S3 機械式トルクリミッター（SAFETY GAP + PARAMETER GAP）

DEC-USER-0002 §4: 機械式トルクリミッター（クラッチ）は「採用候補」ではなく、**設計に含めて検証する Safety Layer**。
ソフトの上限（0.45 N·m、レジスタ比 0.167）+ 機械のリミッターの**二重の層**として、滑りトルク 0.4〜1.5 N·m を掃引した（指定の 0.5〜1.0 を含む）。

## 主な読み（`decision_boundary.md`）

1. **窓は 0.7〜1.0 N·m。** 0.6 N·m（下限の候補）は、個体差 −30%・過渡 ×1.5 を見込むと、追従できたはずの負荷の 15% で滑り、基準（5%）を満たさない。
   個体差 0 なら 0.6 でも 1%（過渡 ×1.5）で、−30% のときだけ足りない → **クラッチの個体差が設計の鍵**（個体差が小さいと確認できれば 0.6 も残る。L1 で確定）
2. 上限側は歯車の破断トルク（**UNKNOWN**、prior 2〜8 N·m）で決まる。滑りトルク × 1.5 ≤ 破断トルクを満たすのは 1.0 まで（個体差 +30% を見込んで）。
   リミッター無しだと、子どもが引く力（最大 238 N × 腕 0.05〜0.30 m = 最大 70 N·m）で、歯車が壊れる確率は 91%（prior 内。頭を持ち上げる場合は 22%）。リミッターがあれば 0%（1.0 N·m 以下）→ 壊れた歯車・破片は誤飲物になる（CAD.md の禁止事項）
3. **トルクの制限だけでは、暫定の接触しきい値（2.7〜6.1 N）を満たせない。** 関節から 20 mm の点で満たすには 0.11 N·m 以下だが、歩容は 0.13〜0.69 N·m を要する。
   → 指の挟み込み・首への接触は**幾何で守る**（5〜12 mm の隙間を作らない、閉じた開口・袋小路を作らない）と、力を逃がす柔らかい外装（mechanically forgiving）
4. リミッターの本来の役目: ソフトの故障時（レジスタが効かない）に、力を 119 N（p95、最大 164 N）から、0.7 N·m のリミッターで 33〜42 N（p95）に下げる。歯車を守る。二重の層として、ソフトの設定に依存しない値にする
5. 配置: **サーボ出力とリンクの間（出力側）**。入力側だと外力が歯車を通る

## config への反映

`safety_limits.torque.mechanical_limiter`（DESIGN_PROVISIONAL）: window [0.7, 1.0]、baseline 0.7（安全側）、個体差 0.30、layout output_side、hardware_verified false。
`tests/test_safety_layers.py` が不変条件（個体差 −30% でもソフトの上限より下で滑らない、ソフトの比から計算しない、1.2 N·m を超えない）を固定する。
