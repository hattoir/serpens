# HG-H1 — 実機試験の計画（シミュレーションから絞った順番）

手順・治具・記録用 CSV は `hardware/prototypes/H1_joint/`。ここは「どの順で何を測れば判断が確定するか」。

## シミュレーションから分かったこと（ACTUATOR_MODEL_SIM、`decision_boundary.md`）

1. **必要トルクは μ_横 にほぼ比例する。** 上限 0.45 N·m（誤差なし）で追従できる確率は、μ_横 0.8 で 86〜89%、μ_横 1.6 で 11〜29%（FW6_HEADYAW、decoupled）。
   トルク上限の誤差が −40% だと、μ_横 0.4 を超えると追従できない。→ H0 の μ_横 と、H1 の「上限の実際の効き」の積で決まる
2. 追従できるかの順位相関は **上限の誤差 e（0.77）> ストールトルク（0.56）**。熱はストールトルクと熱抵抗、ピーク電流はストール電流が支配
3. 承認したレジスタ比 0.167 では、prior の中央で実際の上限は約 0.33 N·m（0.45 より低い = 保守側）。ストールが本当に 27.4 kgf·cm なら 0.45
4. 衝撃力（p50 9 N、p95 19 N）はトルク上限で抑えられない。静的な挟み込み（p50 6 N、p95 16 N）と同じ桁
5. 上限が効かない場合、全関節ストールの電流は 11〜18 A。上限が効いていれば 2.4〜4.6 A → **ヒューズの選定はレジスタの効きの確認が前提**
6. 満充電 8.4 V はメモリテーブル初期値の最高入力電圧 8.0 V を超える（残量一様で 28% の時間）→ 最初に 14 番地を読む
7. 稼働時間の p05 は 12〜26 分（1000〜1500 mAh の想定）。重い床では 30 分に届かない可能性

## 合否（提案）

- 2: 実際の上限が 0.45 N·m × (1 ± 0.2) に入る → e の範囲を ±20% に狭めて HG-H0 / H1 を回し直す。外れる → レジスタ比を作り直す（User 承認）
- 5: 歩容相当の負荷で 60 ℃ に達しない → その負荷の床で連続巡回できる見込み
- 安全の合否は、しきい値を User が決めるまで出さない（OQ-0006）

## 追加: J1（頭ピッチ = Engineering の J7）の不感帯・バックラッシ・上限 0.02 N·m の押す力・床接触の較正（ENTRY-D-0008、2026-09-30）

Design が、口の前縁の高さ（c = 0.1 mm = 1 ステップ 0.083 mm）を J1 で守れるかの見積もりを出した（`docs/design/engineering_answers_2026-09-30.md` §2）。**HG-H1 の prior は位置制御の不感帯・バックラッシを持たない（UNKNOWN）** ので、次を測る。
手順・記録・判定は `hardware/prototypes/H1_joint/j1_head_pitch.md`、参照実装とモデルは `j1_floor_contact.py` / `j1_head_pitch_check.py`（ACTUATOR_MODEL_SIM）。

| # | 測定 | 確定すること |
|---|---|---|
| J1-1 | 不感帯（±20 ステップ、上向き・下向きの両方から） | 接触判定のしきい値（D + 2 以上） |
| J1-2 | バックラッシ（出力側の実測とサーボの読み値の比較。エンコーダが出力側か） | 上げる向きの誤差（D + B） |

| J1-6 | 作業姿勢の重力モーメント | 「受動の柔らかさが成り立たない」の姿勢条件（頭だけ 0.024〜0.035 か、首を上げた 0.2 か） |

**prior での確認**（`j1_head_pitch_check.py`）: 頭だけの重力モーメントでは Design と一致（バックドライブ < 重力 の確率 0%）。**首を上げた姿勢（E-0006 訂正: 0.216〜0.238 N·m）では 37〜60%** で、姿勢による。作業中の上限 0.022 N·m の実効値は 0.0067〜0.0336 N·m（押す力 0.15〜0.76 N）で、バックドライブを超える確率 0%。既定の上限（0.449 N·m）はバックドライブを超える確率 68%。
**合否**: 押す力（サーボ分）≤ 頭の重さ（約 1 N）かつ 2.8 N 以下（暫定しきい値 5.7 N の半分。**5.7 N は暫定**）。安全の合否は User がしきい値を決めるまで出さない（OQ-0006）。
