## 手順（1 試行）

順番は固定: **乗る → 入る → 閉じる**。前の段階が失敗したら、その段階で止めて `fail_mode` を書く。

1. 物を床に置く。中心をランプ先端の真正面から `offset_mm`（0 / 5 / 10）だけずらす。先端から約 45 mm 前。
2. フタを開き 60° に固定する。
3. 試験片を一定の速さでゆっくり前へ押す（目標 20 mm/s。定規とスマホの動画で速さを推定して `push_speed_mm_s_est` に書く）。
4. **乗る**: 物がランプの上に載ったら `ride = 1`。載った位置（先端から物の中心まで）の最大値を `ride_max_rel_mm`。載らずに前へ押した / 横へ逃げた / 下に潜ったなら `ride = 0` と `fail_mode`、押して逃げた距離を `escape_dist_mm`。
5. **入る**: 物の中心がランプ終端を越えて空間に入ったら `enter = 1`、入った深さ（ランプ終端から）を `enter_depth_mm`。
6. **閉じる**: 入ったら（またはシミュレーションの予測どおり入らなくても 1 回は）、フタを手で 60° → 0° に回す。目標の時間 0.3 s / 0.6 s をメトロノームか動画で合わせ、`lid_close_s_est` に書く。閉じ終わって物が空間の中にあれば `inside_after_close = 1`。
7. 各条件 10 回。写真か動画を `photo_file` に。

## この試験で決まること（判断の境界）

| 見るもの | 結果 | 意味 |
|---|---|---|
| 乗る率 | シミュレーションの 0% と同じ（載らない） | 「先端が物の縁の下に入らない」が実物でも成り立つ。先端をさらに薄くする / 低摩擦にするしかないが、印刷では作れない領域 → 別の方式（引き込み・ブラシなど）が要る |
| 乗る率 | 載る（特に絨毯で） | 絨毯の毛が効いている。剛体平面のシミュレーションは悲観側だった |
| 入る率 | 乗ったのに入らない | 乗った物を奥へ送る力が無い（シミュレーションと同じ構造）。フタの掻き込みの形を見直す |
| 閉じる | フタが物に当たらず、物が動かない | 後ろヒンジのフタでは前縁が物を奥へ押せない（下記） |

### フタについての注意（シミュレーションからの指摘）

後ろのヒンジのフタは、閉じるとき前縁が**前かつ下**へ動く（ヒンジまわりの円弧）。空間の天井（ヒンジの高さ）より下へは降りないので、
空間の中の物には触れず、**物を奥へ押せない**。手で回す試験では、実際にフタの前縁が物に触れるかを目で確認して記録してほしい（`notes`）。
奥へ掻き込むには、フタの向き（ヒンジを前側に置く、または物を奥へ押す別の板を付ける）を変える必要がある。
