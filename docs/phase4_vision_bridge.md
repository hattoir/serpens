# Phase 4 — Vision Bridge（模擬画像の Vision で閉ループ）

作成 2026-09-16。**すべて SIMULATED / SOFTWARE_VERIFIED。実カメラでは一度も測っていない。**

## 1. 何が繋がったか

```
仮想世界 ─→ 仮想カメラ（1920×1080 の画像を描く）
            │  故障注入: フレーム欠落 / 暗転 / 遮蔽 / 偽マーカ / 偽の人 / 画素ノイズ
            ↓
         ArUco 検出（本物の OpenCV）→ 床ホモグラフィ → 視差補正
         人の bbox → 足元 → 床座標
            ↓  10Hz、0.1s 遅れて届く（撮影時刻のまま追跡器へ）
         SnakePoseTracker / PersonTracker
            ↓
         World State（ARUCO / PERSON_DETECTOR, simulated=True）
            ↓
         Behavior → SimulatedSnake（仮想 ESP32 + 仮想サーボ）→ 仮想世界
```

| 部品 | 場所 |
|---|---|
| 観測器（真値 / 模擬 Vision） | `serpens/sim/sim_vision.py` |
| セッションへの注入（`observer=`） | `serpens/sim/session.py` |
| 閉ループと採点（真値は採点だけ） | `simulation/vision_loop.py` |
| 故障ごとの表 | `tools/vision_check.py` |
| 試験 | `tests/test_vision_bridge.py`（9） |

**真値は制御に入らない。** `pose_source` は `aruco_sim`。実機の開始条件（`aruco` を要求）はこれを通さない。
World State は `ARUCO` に `simulated=True` を付け、`any_real_vision` は False のまま。

位置誤差は**制御から見た誤差**（いまの真値 − 推定。検出誤差 + 遅れ + 撮影間隔）。

読み方:

- 故障が無ければ位置誤差は p95 で約 3cm。大半は遅れ（0.1s + 撮影間隔）による。
- フレーム欠落 3 割・マーカ片方の遮蔽では止まらない（尾から首を推定する経路が効く）。
- カメラが止まると **0.5s（`pose_max_age_s`）で保持へ入り、映像が戻っても勝手に走り出さない**。
  停止までの惰性は約 31mm。
- 「遠い偽マーカ」の 839mm は**保持中**の値（位置不明のあと、偽マーカと尾が両方見えたので再取得した）。
  機体は止まっており、再開には開始操作が要る。**操作者が画面で位置を確かめずに再開すると誤った位置で走る。**

## 3. この段で見つけて直した穴

1. **同じ ID のマーカが 2 枚写ると、どちらを使うかが検出順で偶然決まっていた。**
   → 重複した ID は「見えていない」扱い（`MarkerObservation.duplicate_ids`）。
2. **首が隠れて偽マーカだけが見えると、位置がそのまま飛んでいた**（尾との距離が離れすぎると
   尾を捨てて首を残す既存の規則が、偽の首を採用していた）。
   → 前回位置から `max_speed_mm_s × 経過 + jump_margin_mm` を超える観測は捨てる。
   位置不明（`stale_after_s`）から戻るときは首・尾の両方が要る。
3. **行動側が自己位置の古さを見ていなかった**（凍った位置のまま走り続けられた）。
   → 古さが `pose_max_age_s` を超えたら保持（`source="知覚"`）。再開は開始操作。
   Vision を通す模擬は待機から始まる。

## 4. 残るリスク（隠さない）

- **近い偽マーカ（動きとして不自然でない距離）は区別できない**（上の表で 226mm ずれたまま走る）。
  2 枚のマーカだけで位置を決める方式の限界。**運用規則: カメラの視野に同じ辞書の ArUco を置かない。**
- 偽の人は本物と区別できず、行動はそれを追う（走行距離が半分になった）。安全上の問題ではないが、展示の質に効く。
- 位置不明からの再取得に偽マーカが混ざると、保持中の位置が誤る。**再開前に画面で位置を確かめる手順が要る。**
- ~~実カメラの経路は自己位置をセッションへ渡していない~~ → **2026-09-18 に `CameraObserver` で接続**
  （`serpens/perception/camera_observer.py`。`--camera 0` / 動画ファイル）。録画（`aruco_file`）は
  実機の開始条件を満たさない。**実カメラの画像ではまだ一度も試していない**（録画は仮想カメラ製）。
- ~~再開前に画面で位置を確かめる手順~~ → **K キーで確認**するまで開始できない（最初と見失った後）。
- 画像は仮想。照明・ボケ・反射・マーカの汚れ・実レンズの歪みは入っていない。
- 遅れ 0.1s と 10Hz は想定値（`vision_sim`）。実カメラで測って置き換える。
