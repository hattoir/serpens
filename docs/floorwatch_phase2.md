# Floor Watch フェーズ 2 — 画像処理（合成画像で筋を通した段階）

作成 2026-09-25、レビュー対応 2026-09-26。**すべて合成画像（SIMULATED）。実写の性能は未測定。** 幾何は DESIGN 値。

## 1. 撮影 → 判定（`serpens/floorwatch/`）

| 段 | 何をするか | 場所 |
|---|---|---|
| 撮影 | **通常 → 斜め照明 → 線光 → 全消灯 → 通常** の 5 枚。最初と最後の通常画像が `motion_max_px`（1px）以上ずれたら撮り直し（`MotionError`）。**照明の違う画像同士の位置合わせはしない** | `detect.detect` |
| 背景 | **基準床は使わない**（実機では同じ視点の「物の無い床」は手に入らない。姿勢誤差は cm 級）。通常画像に低次の多項式面を頑健に当てはめ（外れ値 = 物・汚れを除きながら）、その差で前景。σ は MAD とカメラ雑音の下限の大きい方 | `detect.robust_background` |
| 斜め照明 | LED は**あご**（床から 6mm、カメラの真下付近、前向き）。影は物の**奥 = 画像の上側**に出る（視野中心の 1 円玉で約 2cm）。斜め / 通常 の比（床の模様の濃さが打ち消される）を全体の中央値で正規化 → 影。塊の**上辺から上**を見る。明るさの差が無い物（床と同じ色）は影だけから候補を作る（影の手前 = 物） | `detect._shadow_only_boxes` |
| 線光 | 行ごとに線の位置（半値以上の連続区間の輝度重心）。基準は較正した光の面が予測する床の線と、**物の前後の床上の線**（局所の中央値）。横ずれ → 光の面との交点で高さ。線幅は自動推定。線の異常（途切れ・持ち上がり）だけからも候補を作る | `detect.trace_line`, `_line_only_boxes` |
| 高さ | 線が乗った行が `line_min_rows` 以上 → `measured`。線が途切れた（鏡面・黒い物）→ **`height_mm: null` + `specular_break`**。線から外れ → `off_line`。行が足りない → `too_few_rows`。**0 とは絶対に書かない**（0 = 平ら = 汚れと読まれる） | `detect._candidate` |
| 候補 | 大きさ（足元の局所スケールで画素 → mm）、高さ（または理由）、影、途切れ、形（塊 / 線状）。**途切れ + 円形（床上の縦横比 0.5〜2）+ 直径 5〜25mm → `metal_disc`**（ボタン電池の可能性）。線状 → 継ぎ目・段差（物ではない）。塊で影なし・高さなし → 模様/汚れ | `detect.Candidate` |
| 危険度 | 種類 × 確信度 × 大きさ係数 × 子どもの距離（不明 = 近い）× 届くか。**高さの係数は掛けない: 測れない = 出っ張り扱い（1.0）**。ボタン電池・磁石・薬・metal_disc は別枠で必ず通知 | `risk.assess` |

線の幾何（`geometry.py`）: カメラ床から 30mm・下向き 25°・f = 1000px（レビューの設計値 = `synthetic_ref`。実機の床見は UXGA
f ≈ 1256 px ASSUMED、画素単位のしきい値は f に比例して拡大。`floor_watch.camera.modes`）→ 視野中心は床 71mm 先。投光部はカメラの横 30mm・同じ高さ、
光の面を内側へ 45° → 床の線はカメラ中心線の真下を前後に走り、高さ H の面では横へ H だけずれる。
1 円玉 1.5mm → 21.3px、床の 0.3mm 段差 → 4.3px。**名目の基線は式に入れず**、`LightPlane.fit` が 1 円玉 1・2・3 枚の段から面を当てはめる。
注意: 面 x = z なので、高さ H の物の上面に線が届くのは H + 線の半幅 ≤ 半径 のとき。細く高い物（ビーズ 6mm）は線が側面に当たり、
高さは真値より低く出る（途切れと影で拾う）。

## 2. 合成データセット（`dataset.py`、`tools/floorwatch_eval.py --synthetic`）

品目: 1 円玉（20mm × 1.5）、M10 ステンレス座金（20mm、鏡面 = CR2032 相当）、M6 座金 3 枚重ね（12mm × 4.8、鏡面 = LR44 相当）、
ビーズ（6mm）、食べかす（4mm）、黒い物、透明な物。位置 6 か所（線上 3 + 線外 3）。陰性: 汚れ・模様・何も無い（各 6）、
**床の継ぎ目 10**（前後方向 / 左右方向 × 溝 / 段差、0.2〜0.5mm。左右方向の段差は影も落とす）。合計 n = 70。

**2 段評価**（レビュー 6）: `patrol` = 巡回中の発見（線なし、通常 + 斜めだけ）/ `inspect` = 止まって線光あり。
inspect で線から外れた物の見逃しは「狙いの問題」（`aiming_miss`）として線の性能とは別に数える。95% 信頼区間（Wilson）を付ける。

結果（2026-09-26、**SYNTHETIC**、撮影ごとの雑音は毎回違うので実行ごとに揺れる）: patrol **98〜100%**（41〜42/42、95%CI 88〜100%）、
inspect **98〜100%**、誤報 **0%**（0/28、95%CI 上限 12%）。見逃しが出るときは線外・近（55mm）の食べかす（4mm）。
実機モード（UXGA 1600×1200、f ≈ 1256 px ASSUMED、しきい値は f に比例。`--mode` 省略時。2026-09-27）: patrol **98%**（41/42）、inspect **100%**（41/41）、
誤報 **0%**。見逃し 1 は線外・近の食べかす（画像の端）。視野 65° では画像の上端が地平線を越えるので、上の行は床ではない（合成では模様で埋まる）。線上の 1 円玉は 1.5 ± 0.2mm。鏡面の座金は全て `specular_break` → `metal_disc` → 必ず通知。
**これは楽観値**: 合成の影は理想的（縁がくっきり、床の照り返しなし）、線は乱れない、床の模様は 1 種類。実写では下がる前提で、
閾値（`floor_watch.detect`）はここで調整する。黒い物・透明な物も線が乗らず `specular_break` → `metal_disc` になる（安全側の誤り。
分類器ができるまで許容）。

## 3. 実写データセットの手順（フェーズ 2 の完成条件はこちら）

- 治具で頭と同じ条件: カメラ床から約 30mm・下向き 25° 前後、**斜め照明 LED はあご（床から約 6mm、カメラ真下付近、前向き）**、
  通常照明はレンズのすぐ横、線光はカメラの横 30mm・同じ高さ・45° 内向き、**レーザーは使わない**。
- 撮影順 **通常 → 斜め → 線光 → 全消灯 → 通常**。最初と最後の通常が 1px 以上ずれたら撮り直し。基準床は撮らない。
- 床: 自宅フローリング → 後で 1 種類追加。**継ぎ目（溝・段差）を必ず含める**。照明: 昼 / 夜の室内灯 / ソファ下の暗がり。
- 品目: §2 の 7 種 + 汚れ・模様。線上と線外の両方に置く。
- 1 地点 = 5 枚 + `labels.csv`（`dataset.LABEL_COLUMNS`）。`source` は PHONE / HEAD_CAMERA。
- 較正: 撮影の最初に 1 円玉 1・2・3 枚の段を線の上に置いて撮る（`LightPlane.fit` 用）。
- 評価: `tools/floorwatch_eval.py --root data/floorwatch/<set>` → `docs/verification_status.md` に 2 段の検出率・誤報率と信頼区間を記録。

## 4. まだ無いもの（正直に）

- 実写。手持ちカメラの機種・治具写真は未回答。線幅の初期値 3mm（40px）、二重スリットの実効幅は未検証。
- 候補の**種類**の分類器。`metal_disc` は代用（途切れ + 円形 + 5〜25mm）で、黒い物・透明な物も拾う。
- 合成の限界: 物は円盤（側面を描かない）、継ぎ目の影は左右方向の段差だけ、床の照り返し・環境光のむらは無い。
- 5 枚の撮影中に機体が動いたときは撮り直すだけ（位置合わせはしない）。
