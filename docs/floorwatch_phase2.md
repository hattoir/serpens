## 1. 4 枚 → 判定（`serpens/floorwatch/`）

| 段 | 何をするか | 場所 |
|---|---|---|
| 撮影 | 全消灯 / 通常 / 斜め照明 / 線光 の 4 枚。各照明画像から全消灯を引く。撮影中は静止 | `detect.py` |
| 位置合わせ | 位相相関で平行移動だけ。**同じ照明の画像同士だけ**（斜め→通常、基準床→通常）。線光は内容が違うので合わせない | `detect.align` |
| 基準床との差分 | いつもの床（通常照明）との差 → 前景（模様・汚れも入る）。σ は MAD とカメラ雑音の下限の大きい方 | `detect.detect` |
| 斜め照明の比 | 斜め / 通常 の比（床の模様・汚れの濃さが打ち消される）→ 局所的な影 = 出っ張りの証拠。影は床に落ちるので、上面の行より下を見る | 同上 |
| 線光 | 行ごとに線の位置（半値以上の連続区間の輝度重心）。**床の線からの横ずれ → 較正した光の面と視線の交点 → 高さ**。線幅は式に入れず、行ごとの区間長の中央値で自動推定 | `detect.trace_line`, `geometry.LightPlane` |
| 途切れ | 床の線が塊を通るのに線が無い行が `dropout_rows_min` 以上 → 出っ張りの証拠（鏡面）。**高さが測れないことを安全の根拠にしない** | `detect._candidate` |
| 候補 | 大きさ（足元の局所スケールで画素 → mm）、高さ、影、途切れ、形（塊 / 線状）、根拠 | `detect.Candidate` |
| 危険度 | 種類 × 確信度 × 大きさ係数 × 高さ係数 × 子どもの距離（不明 = 近い）× 届くか。**ボタン電池・磁石・薬は別枠で必ず通知** | `risk.assess` |

線の幾何（`geometry.py`）: カメラ床から 30mm・下向き 25°・f = 1000px → 視野中心は床 71mm 先。投光部はカメラの横 30mm・同じ高さ、
光の面を内側へ 45° → 床の線はカメラ中心線の真下を前後に走り、高さ H の面では横へ H だけずれる。
1 円玉 1.5mm → 21.3px、床の 0.3mm 段差 → 4.3px（テストで確認。**名目の基線は式に入れず**、`LightPlane.fit` が
1 円玉 1・2・3 枚の段から面を当てはめる。テストでは名目 45° からずれた面でも高さが戻ることを確認）。

## 2. 合成データセット（`dataset.py`、`tools/floorwatch_eval.py --synthetic`）

品目: 1 円玉（20mm × 1.5）、M10 ステンレス座金（20mm、鏡面 = CR2032 相当）、M6 座金 3 枚重ね（12mm × 4.8、鏡面 = LR44 相当）、
ビーズ（6mm）、食べかす（4mm）、黒い物、透明な物。陰性: 汚れ・模様（高さ 0）・何も無い。位置 3 か所（線の上 / 左 8mm・遠 / 右 6mm・近）。

結果（2026-09-25、n = 30、**SYNTHETIC**）: 検出率 **90%**（19/21）、誤報率 **0%**（0/9）。
線の上に乗った物は高さが ±0.2mm で戻る（1 円玉 1.49、食べかす 1.14 / 正解 2.0 は塊の縁の影響）。
鏡面の座金は線が消え「途切れ」で拾う（高さは 0 と記録、測れないことを安全の根拠にしない）。
線から外れた物は線の証拠を持たず、影だけで拾う。**見逃し 2 件**はどちらも左 8mm・遠（80mm）の小さな物（ビーズ、透明な物）:
遠くの小さな物の差分が弱く、影も小さい。実写では照明角度（15°/30°）と閾値をここで調整する。

## 3. 実写データセットの手順（フェーズ 2 の完成条件はこちら）

- 治具で頭と同じ条件: カメラ床から約 30mm・下向き 25° 前後、斜め照明 LED は床から 8mm / 17mm（照射角 15° / 30°）、
  線光はカメラの横 30mm・同じ高さ・45° 内向き、**レーザーは使わない**。
- 床: 自宅フローリング → 後で 1 種類追加。照明: 昼 / 夜の室内灯 / ソファ下の暗がり。
- 品目: 1 円玉、20mm ワッシャー、M10 ステンレス座金、M6 座金 3 枚重ね、ビーズ、食べかす、黒い物、透明な物、汚れ・模様。
- 1 地点 = 4 枚 + `labels.csv`（`dataset.LABEL_COLUMNS`）。`source` は PHONE / HEAD_CAMERA。基準床 `reference_<floor>.png`。
- 較正: 撮影の最初に 1 円玉 1・2・3 枚の段を線の上に置いて撮る（`LightPlane.fit` 用）。
- 評価: `tools/floorwatch_eval.py --root data/floorwatch/<set>` → `docs/verification_status.md` に検出率・誤報率を記録。
