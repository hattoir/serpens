## HT-002（P0）J1 の押す力の測定（ロードセル + HX711）

- **何を**: J1 の横スキッド前端（腕 44.2 mm）が床（荷重計）を押す力。トルク制限レジスタ（48 番地）= 8 / 12 / 20 / 167（1000 = ストールの 100%）で。**サーボ OFF（重力だけ）の荷重も測り、差をサーボ分とする。** 予想: 8/1000 で 0.15〜0.76 N（HG-H1 の prior、実効上限 0.0067〜0.0336 N·m ÷ 0.0442 m）。
- **なぜ**: 「上限 0.022 N·m で頭の重さ（約 1 N）以下に抑えられるか」「動き出しの最小の上限 τ_move」の実測（J1-3 / J1-4）。prior の実効上限の誤差 e ±40% を置き換える。
- **手順**:
  1. **ロードセル**: 定格 500 g〜1 kg（≈ 5〜10 N）、ひずみゲージ式のビーム型（またはボタン型）。**予想 0.15〜0.76 N は定格の 3〜15%** なので、500 g が望ましい。HX711（ゲイン 128、80 SPS）で読む。校正は既知のおもり（20 / 50 / 100 / 200 g）で 4 点（傾きと直線性。`force_n = (raw − tare) × N/count`）。
  2. ロードセルを、床面の高さに固定（剛い台。たわみ 0.1 mm 以下）。頭の模型の横スキッド前端が荷重面の中心に載るように置く（J1 軸から 44.2 mm。**測る力は、腕 44.2 mm の先の鉛直成分**）。
  3. 各条件の前に**風袋（tare）**を取る（頭を持ち上げた状態）。条件: 48 番地 = 8 → 12 → 20 → 167（**小さい方から**）、位置指令 = 床より 10 ステップ下（約 0.9°）。各条件で 10 秒（80 SPS）記録して平均・標準偏差。
  4. 同じ位置で **トルク OFF（重力だけ）**の荷重を測る（頭の重さの分担）。
  5. 各条件 5 回（毎回、頭を持ち上げてから下ろす）。温度・電圧・現在負荷（60 番地）・現在電流（69 番地）も記録。
- **道具**: ロードセル（500 g〜1 kg）+ HX711 基板、読み出し用の MCU（ESP32 / Arduino）または PC、既知のおもり、頭の模型、ST3215-C044、安定化電源、電源断スイッチ。**購入リスト**（下）を参照。
- **記録先**: `hardware/prototypes/H1_joint/j1_push_force_YYYYMMDD.csv`（雛形 `j1_push_force_template.csv`。列: date, operator, test_id, register_torque_limit, torque_on, goal_below_floor_steps, force_n_mean, force_n_sd, n_samples, load_reg, current_a, temp_c, voltage_v, note）。
- **合否（提案）**: サーボ分の力 ≤ 頭の重さ（約 1 N）かつ 2.8 N 以下（**5.7 N は暫定。安全の合否は User がしきい値を決めるまで出さない**）。

## HT-003（P0）衝撃ピークの測定（ADS1256）

- **何を**: J1 がストッパー（窓の端）に当たったときの**衝撃のピーク力**。速さ 60 / 90 / 120 °/s（**ファームの `LIMIT_HEAD_SPEED_DPS` = 120 °/s が上限**。180 °/s はベンチのサーボを直接駆動する場合だけ。機体の経路では出ない）、緩衝（なし / TPU パッド E 10 MPa・厚さ 4〜6 mm）、端の手前の減速の有無で。**同じ装置で、フード昇降の落下のピーク（10 / 20 mm/s）も測る**（`flank_v.md` §F）。
- **なぜ**: 衝撃は**トルク上限では抑えられない**（HG-H1）。Engineering の見積もり（ω√(J k)。鋼 + 減速なし 120°/s で 12〜63 N（パッドの有無による））は prior。J（反射慣性）と k（剛性）が UNKNOWN。ピンの強度・安全率（`j1_range_opt_2026-09-30.md` §4）の根拠になる。
- **手順**:
  1. **ロードセル**: 5〜10 kg 級（固有振動数が高い小型の圧縮型）+ **ADS1256**（PGA 64、10〜30 kSPS、単一チャンネル）。**ロードセルの固有振動数を、軽いハンマーの打撃で確認**（ピークが装置の共振で歪む。カットオフはサンプリングの 1/5 以下）。校正は静的な既知のおもり（0.5 / 1 / 2 kg）。
  2. 窓の端を模した当たり面（PLA 板、次に TPU パッドを貼ったもの）をロードセルに固定し、J1 の動きの端に置く（ピンの位置 = 腕 36〜48.5 mm）。
  3. **トルク上限 8/1000（0.022 N·m）の状態から始める**。J1 を指定の速さで当てる。**167 は最後**（上限が効いているかも同時に確認）。各条件 5 回。10 kSPS で、当たる前 100 ms から後 200 ms を記録（トリガー）。
  4. ピーク力・立ち上がり時間（10〜90%）・減衰を記録。
  5. **J・k の当てはめ**: `F_peak = ω √(J k)`。同じ k（当たり面）で ω を変えて F_peak が ω に比例することを確認 → 傾きから √(J k)、k は立ち上がりの力の傾き（力 ÷ 押しつぶし）から。
- **道具**: ロードセル（5〜10 kg 級）、ADS1256 基板、SPI で読める MCU（ESP32 など）または PC、当たり面（PLA / TPU 各種）、頭の模型、ST3215-C044、電源断スイッチ、ハンマー（共振の確認）。購入リストを参照。
- **記録先**: `hardware/prototypes/H1_joint/j1_stopper_impact_YYYYMMDD.csv`（雛形 `j1_stopper_impact_template.csv`。列: date, speed_dps, damper, decel_deg, torque_limit_reg, peak_n, rise_ms, decay_ms, sample_rate_hz, load_cell_fn_hz, note）。
- **AI が次にやること**: J・k を `assumptions.yaml` に入れ、ストッパーの安全率（鋼ダウエル φ3 の曲げ）と最適化を更新。PLA ピンが足りるか、TPU パッドの効果を実測ベースで再判定。
