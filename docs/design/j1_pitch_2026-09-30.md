## 3. 取り込み機構との関係（頭の口の高さ）

J1 軸（−181.8, z 32.4）から口の下の前縁（x −236、床）まで **63.1 mm**（水平 54.2、垂直 32.4）。頭を **+θ° 上げると、口の前縁が床から持ち上がる**（`32.4(1 − cosθ) + 54.2 sinθ`）:

|---|---|
| −5° | −4.6（床にめり込む = 胴が持ち上がる） |
| −2° | −1.9 |
| 0° | 0 |
| +1° | 0.95 |
| +1.3° | 1.24 |
| +2° | 1.9 |
| +5° | 4.9 |
| +10° | 9.9 |

Engineering の t・c（段差 0〜1.0、すき間 0〜1.0 mm）と比べると、**持ち上がりが 1 mm を超える +1.1° 以上は、口の下に隙間ができる**。作業窓 −2〜+1° は、すき間の面でも取り込みの面でも整合する。
