## 1. 今の第一候補（CAD_CONCEPT、人の評価 0 回）

頭 SD-01E3（平らなあごの Bean 頭 ＋ 横の口の線）、J1 は VISOR（首の芯＋頭巾＋襟）、胴は同心ナックル、あごの板（顎板のそり）、照明は頬の下（斜め）と口の線（通常）。Head Yaw ±30°（Design の提案、Engineering の安全側の上限と一致）。

## 2. すき間チェック（5〜12 mm を作らない、Engineering の要求）

方法: Fusion の STL を姿勢ごとに動かし、0.5 mm のボクセルで検査（外形のみ。内部部品・公差・たわみなし）。

| 姿勢 | カバーなし | KNUCKLE DRUM 後 |
|---|---|---|
| p0 まっすぐ | 144 mm³ | 124 |
| p1 | 6807 | 2558 |
| p2 | 7176 | 2939 |
| p3 | 6492 | 2250 |

- **原因**: 同心ナックルの 4 mm 一定は、玉が完全な円柱の高さ（z 30〜70）でしか成り立たない。樽形の絞りで玉の脇が痩せると、曲げたとき椀とのすき間が 5〜10 mm に広がる。
- **直し（実装済み）**: 各関節の玉の脇を z 8〜76 で完全な円柱に戻す（KNUCKLE DRUM: J3〜J5 は R46、J2 は R34）。胴の層は約 90 % 減。
- **r の範囲**: J3〜J5 は r = 42.5〜50 mm の輪（玉と椀のあいだ）、J2 は 28〜49、J1 はピッチで変わる（`gap_check_report2_2026-09-30.md` §2）。
- **効かなかった案**: 脇のフラップ（FLANK SKIRT STUDY。増えた）、椀の縁の唇、あごのフラップ。理由は報告 §5。
- 頭の下の後ろの埋め物: 172 → 2 mm³（p0）。尾の「刃」は検査ツールの不具合の人工物で取り下げ済み。

## 6. 主な決定（ユーザー承認済み）

CSAR 採用、6 本目 = Head Yaw（暫定）、子どもが近い間は撮影を後回し（後ろ向きに下がらない）、対象は 3 歳未満（安全は 6 歳まで）、ヨー合計 145°（Head Yaw は別の安全軸）、KNUCKLE DRUM を進める。詳細は `ai-shared/design-state.md` と `ai-outbox/decisions/`。

## 7. 主な教訓（`ai-outbox/lessons/2026-09-29_LESSON-DESIGN-0001.md` の 1〜22）

- 理屈で「幾何では消せない」と結論する前に、検査の数字（r・z・幅の分布）で原因の位置を確かめる。
- 自作の検査が出した「欠陥」は、まず CAD の形（STL の境界の数値）と照合する。箱の位置を変えて結果が変わらないことを確認する。
- Fusion の `body.deleteMe()` は後続フィーチャごと消える。既存の体を直すときは押し出しの切り取り。
