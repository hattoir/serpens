> 先頭の注意: KNUCKLE DRUM 後も、まっすぐ比で約 20 倍（18〜24 倍）のすき間の体積が残る。背板は未解決、J1 ピッチは回答待ち。

## A. 印刷して確かめる（Design は印刷・購入をしていない）

1. **円柱肩の試験片 R46 を印刷**（A1、PLA、インフィル 15 %、支え不要。約 270 g）: `docs/design/knuckle_test/print/KNUCKLE_R46_*.stl` ＋ `GAUGE_5mm_12mm_PLA.stl`
   - 板に椀 B を差し、玉 A を軸に載せ、0・±25・±50° で **探針 d5・d12 が入るすき間が無いか**、見た目・触感を見る
   - 見てほしいこと: 関節の玉の脇が円柱の肩として **5〜10 mm 張り出す外観**（「膝」）でよいか
2. **R34（J2）も印刷**（約 233 g）。**椀 B の STL に開いた辺 18 か所**。スライサの「修復」を通す
3. **試験片 B を印刷**（`docs/design/test_piece_b/print/`）: フード・リップ・スペーサー・クランプ棒は PLA、**スカートは TPU（A1 は外付けスプール、AMS を通さない、低速）**。手順・質量・試す物（1 円玉、CR2032、ビーズ、立方体）は README
4. 結果（写真・気づき）を Design に返す → KNUCKLE DRUM・試験片 B の形を直す

## B. 判断してほしいこと

| 判断 | 選択肢・補足 |
|---|---|
| 試験片 B の **前縁の「段差 0/0.3/1 mm」の解釈** | Design は「リップ板の下面が床から浮く高さ」と解釈した（スペーサー厚 1.0 → 段差 0、0.7 → 0.3、なし → 1.0）。違うなら教えてほしい。**試験片 B の元のブリーフがこの会話に無い**ので、A の続きと読んだ |
| KNUCKLE DRUM の **外観**（関節に膝） | 承認済み。実物を見て、続けるか調整するか |
| **物を拾う・回収する機構を第二段階に入れるか**（OPEN-012） | `PRODUCT.md` は「やらないこと」。A 研究のみ（現状）/ B 第二段階として頭に統合（PRODUCT.md の更新が先）/ C 見送り |
