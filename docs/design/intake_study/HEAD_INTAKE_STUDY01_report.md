## 0. 先に読む 5 点

1. **Fusion では元ファイルを変えていない。** ブリーフの `Serpens_FW02_SNAKEBELLY_R03R04_BASE_NOT_FOR_PRINT` は **v4 ではなく v5 が「卵形シェルのある版」**（v4 は全身スタディでシェルなし）。元は v5・未変更のまま（タイムラインの件数も同じ）。作業は複製 **`Serpens_FW02_HEAD_INTAKE_STUDY01_NOT_FOR_PRINT`**（Serpens フォルダ）に「HEAD INTAKE STUDY 01 - NOT PARTS」を足した。複製の理由は、FW02 が Engineering の CAD なので、ブリーフの「既存のボディは変更しない」を確実にするため
2. **卵形の頭（a38 r38）にはこの機構は入らない。** 30×30×15 の空間の **42〜66 %** が卵の外に出る（§4）。SD-01 の Bean 頭（平らなあご）なら **約 92 %** が内側に収まる
3. **ヒンジ高さ 12.0 mm だと、腕の先端が 12° の TPU ランプを 90〜115° の間で削る**（最大 約 8 mm³）。閉形式の下限: `hinge_h ≥ tip_t + √(arm_len² + (arm_t/2)²) / cos(ramp_angle)` ≈ **12.2 mm（先端 0.4）/ 12.4 mm（先端 0.6）**。12.3 mm で干渉 0 を確認した
4. **閉じた腕が塞ぐのは入口の高さ 15 mm のうち 2 mm の帯だけ**（Z11〜13）。ブリーフの動作は変えていないので、これは「入口は腕だけでは閉じ切らない」という所見として報告する（§5）
5. 安全・製品の観点の注意が 3 つある（§8）。特に **PRODUCT.md の「やらないこと: 物を拾う・回収する」との関係**

## 3. 機構の解釈と仮定（ブリーフの曖昧な所）

- 座標: ランプ先端を原点、後ろ向き（CAD の +X）を x'、床 Z = 0。ヒンジは先端の真上 (x' = 0, Z = hinge_h)、軸は Y
- 腕の動き: φ = 0° で前向き水平（−X）→ 90° で真下（先端 Z = hinge_h − arm_len = 0.5）→ 180° で後ろ向き水平（+X、Z 11〜13、x' 0〜11.5）。**ブリーフどおり、動作は変えていない**
- **空間の位置は「ランプ先端の直後から」を文字どおり x' = 0 から 30、Z 0〜15 とした**（ランプは空間の床の下の斜面として空間の中にある）。別の読み（ランプの後端から空間が始まる）なら `space` のスケッチの X を変える
- ラッチは「閉じた腕の先端の後ろ」に 5×6×5 の参照箱を置いただけ。**機構は設計していない**（[A]）
- SG90 は 22.5×12.2×22.7 の参照箱（[R] データシートの一般値、実測なし）。出力軸を蝶番の軸に合わせ、空間の +Y 側（Y 16.2〜38.9）に置いた

## 5. 可動確認（項目 3）: 腕の角度ごとの干渉体積（mm³、hinge_h 12.0、tip_x −219）

| φ | ランプ | 空間 | SG90 | ラッチ | HEAD BELLY 殻 | スキッド |
|---|---|---|---|---|---|---|
| 0° | 0 | 0 | 0 | 0 | 140.1 | 0 |
| 45° | 0 | 14.0 | 0 | 0 | 84.4 | 89.6 |
| 90° | **0.8** | 322.0 | 0 | 0 | 95.6 | 252.0 |
| 135° | 0 | 630.0 | 0 | 0 | 254.0 | 89.6 |
| 180° | 0 | 644.0 | 0 | 0 | 69.5 | 0 |

- 5° 刻み: 腕がランプに入るのは **90〜115°**（95°: 4.2、100°: **8.2**、105°: 7.7、110°: 3.3、115°: 0.5 mm³）。掃引の合計 13.5 mm³。腕の先端の軌跡（円）は先端の直下で水平、ランプは 12° で上がるので、先端の真下を過ぎた直後に食い込む
- **hinge_h 12.3 では全角度で 0**（ランプ・ベースとも）。式の下限は約 12.2 mm
- 腕の掃引が **殻に 804.5 mm³**、**スキッドに 1,619.9 mm³** 入る → 口の窓（殻の切り欠き）が要る
- 空間との交差は「腕が空間の予約体積に入る量」。閉じた姿勢（180°）で 644 mm³（空間の 4.8 %、上端の Z11〜13）
- **入口の塞がり方**: 腕が真下を向く 90° では入口（x' = 0）を Z0.5〜12 で塞ぐが、180° で後ろを向くと入口の Z0.4〜11 が開く。**閉じ終わりで塞ぐのは Z11〜13 の帯だけ** → 入口を閉じるには別の部材（幕・扉）か、腕の断面の変更（ブリーフの動作を変えない範囲で、腕の先端に下向きの縁を付ける等）が要る。Design の案は出していない

## 6. 試験片 A（手で回す）

構成（各バリアント）: **ベース PLA**（側壁 1.6、内幅 39.8、床板の上面 = ランプ後端の高さ 2.10 / 3.59、後壁 1.6、ロッド穴 D8.4 のボス、ピンの縦長穴 D2.2 × Z12.0〜12.3）、**ランプ TPU**（幅 40、両側に 0.1 mm の圧入）、**腕 PLA**（幅 38、板厚 2、ボス D4.6 / 穴 D2.2）、ピン（D2 の棒か M2 ねじ、別途）。

| 部品 | サイズ（STL から）| 体積 | 材料 | 印刷の向き |
|---|---|---|---|---|
| A8 ベース | 66.1×43×16 | 6,784 mm³ | PLA | モデルのまま（床板を下）。ロッド穴は水平なので **D8.4 にリーマ**で仕上げる |
| A15 ベース | 73.1×43×16 | 8,920 | PLA | 同上 |
| A8 / A15 ランプ | 8×40×2.1 / 15×40×3.59 | 400 / 1,197 | **TPU** | 底面を下、先端を前。先端 0.4 mm は 0.2 mm 層で 2 層。**薄すぎて出なければ先端 0.6 mm に**（`tip_t`） |
| 腕（共通） | 13.7×4.6×38 | 約 1,190 | PLA | **38 mm の端を下に立てる**（ピン穴の軸が垂直になり穴が丸く出る） |

- **最小肉厚**: 側壁・後壁・ボスの壁 1.6、ピン穴まわりの前の耳 1.4、床板 2.1〜3.59、腕のボスの壁 1.2（穴 2.2 と外径 4.6）。**ランプ先端の 0.4 mm はブリーフのとおり別パーツの TPU にした**（PLA の最小肉厚 1.2 未満）。最初は腕のボス外径を 4.4 にして壁が 1.1 mm と最小肉厚を割っていたが、パラメータの式（穴 + 2 × wall_min）に直して 1.2 になった
- **試験片の可動確認**（hinge 12.0 / 12.3、5° 刻み）: 腕 × ベース = **0 mm³**（全角度）。腕 × ランプ = 12.0 で最大 11.1 mm³（掃引 18.3）、**12.3 で 0**。腕は壁から 0.9 mm ずつ離れている
- **ピンの位置**: 壁のピン穴は Z12.0〜12.3 の縦長穴（D2.2）。**ピンを下に置けばブリーフの 12.0、0.3 mm の shim（紙・テープ）で上に押し上げれば 12.3**。実物でどちらが引っかからないかを見る
- **組立て**: (1) ロッド穴を D8.4 のドリル／リーマで仕上げる (2) ベースの側壁の間にランプ TPU を先端を前にして押し込む（床板の前の端に突き当てる）(3) 腕のボスを両側壁の縦長穴の位置に合わせ、D2 のピンを通す。腕が手で軽く回ること (4) ロッド（φ8 想定）を後ろのボスに差し込む
- **手で回す確認の見方**: 腕を前 → 下 → 後ろへ回し、(a) 先端が TPU に引っかかるか（hinge 12.0 / 12.3）(b) 1 円玉・ビーズ・ボタン電池の代用（**本物の電池は使わない**）を先端で奥へ押せるか (c) ランプを 8 と 15 で比べる

## 7. シミュへの推奨（ブリーフの「ランプ長・ヒンジ高さ」）

- **ヒンジ高さは 12.2〜12.4 mm 以上**（12° のランプ、腕 11.5、板厚 2、先端 0.4〜0.6）。式は §0。12.0 のままなら**ランプに先端の通り道の溝（半径 arm_len + 0.3 の円弧）**を切る必要があり、先端 0.4 mm の TPU に 0.3 mm の溝は印刷が難しい
- ランプ角度を下げるとヒンジ高さの下限も下がる（`hinge_h ≥ tip_t + arm_len / cos(ramp_angle)`、角度 8° なら 12.2 → 12.1 程度）が、床から空間の床までの登りが長くなる
- 腕の先端の通り道が床から 0.5〜0.8 mm（12.0 / 12.3）なので、**0.5 mm より薄い物（紙・平たい薄片）は下をくぐる**

## 8. 注意（Design が言うべきこと）

1. **製品範囲**: `PRODUCT.md` §2 は「やらないこと: 物を拾う・回収する」、見送った構想に「物の回収」を挙げている。ブリーフは「第二段階」と書いているので、これは意図した拡張だと理解して進めたが、**PRODUCT.md と Project Vision を変える判断は User の仕事**。Design は PRODUCT.md を変えていない
2. **子どもに対する安全（未検証）**: 頭の中で閉じる腕は指の挟み込み・押し付けの危険がある。SG90 は一般に約 1.8 kgf·cm（0.18 N·m）とされ [R]、腕の先端では約 15 N になる計算（0.18 N·m ÷ 0.0115 m、実測なし）。**この力を接触の安全の閾値（USER-DEC-SERPENS-0003 #2、Engineering が子どもの人体寸法・規格・文献から導出）と比べる必要があり、確認までは SAFETY_UNVERIFIED**。ラッチを「アプリからのみ」開ける方針も、開ける場所・時刻が CSAR（子どもが近い間は危険物のそばで動かない・光らせない・見せない）と衝突しないことが要る
3. **ボタン電池を頭の中に溜める**危険（短絡・発熱・LiPo や SG90 との近さ・取り出し時の露出）は設計していない。試験は代用品で（本物の電池を使わない）
