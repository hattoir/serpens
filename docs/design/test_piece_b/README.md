## 機能の組み立て

- **段差の切り替え**: リップのペグ 2 本を、（スペーサー 2 個を通して）フードの耳の穴に差す。段差 0 = 厚さ 1.0、0.3 = 厚さ 0.7、1.0 = スペーサーなし。リップの下面の高さ = 1.0 − スペーサーの厚さ（床から）。ペグは摩擦（必要なら少量の接着）。
- **垂れ布の取り付け部**: 屋根の前縁の座（8×54×3）に、TPU の薄板 **0.4〜0.6 mm [B]** を載せ、クランプ棒を M2 ねじ ×2（下穴 d1.6、深さ 3.2 [A]）で留める。布は前縁から前・下へ垂らす（受け身の垂れ布）。
- **スカート**: 足の帯の下面の溝に、TPU の舌を差し込む（差し替え式）。
- **棒 φ8 の差し込み穴**: 後ろのブロック 22×22 に **d8.4**（φ8 + 0.4、くちばしの試験片 A の rod_d + 0.4 と同じ [A]）、深さ 20。手で棒を押して進める。**止めねじは無い**（[A] 必要なら M3 を足す）。

## 印刷

- PLA: 0.4 ノズル、層 0.2、**壁 4 周（1.6 mm）**、インフィル 15 %（フードは壁だけでほぼ中実）。フードは屋根を下にして置く（STL のまま）。ロッド穴は水平（小さいので橋渡し可。だめならティアドロップに直す）。
- TPU（95A 程度 [A]）: **A1 では外付けスプールで、AMS を通さない**。0.4、層 0.2、低速（20〜30 mm/s）、リトラクション最小。スカートは寝かせて印刷済み。
- 質量（概算 [C]）: フード 21 g（中実）、リップ 1.7 g、クランプ棒 1.1 g、スペーサー 各 0.1 g 以下、スカート H3 1.2 g / H6 1.9 g（TPU 1.2 g/cm³ [R]）。

## 限界

- 形の確認は Fusion の STL の断面（`b1_check.png`）まで。**実物の嵌合・摩擦・TPU の柔らかさ・ペグの保持は未確認**。
- 壁 1.6 は [B] の最小 1.2 以上だが、ロッド穴の上下の壁（4.1）・足の帯の溝の側壁（1.2）が最小ぎりぎり。
- スカートを付けるとフードが H 上がり、リップの床からの高さが変わる（上の (3)）。
- 前縁の段差の解釈が違う場合は、リップ板とスペーサーだけ作り直せばよい（フード本体は共通）。
