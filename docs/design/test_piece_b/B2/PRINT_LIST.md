## 材料・印刷設定

- 材料: **PLA（Generic PLA）**。
- 積層: **0.20 mm 標準**、プレート: **スムース PEI**。
- **エレファントフット補正 0.1〜0.2 mm**（スライサーの設定）を入れる。床板の底と、フードの壁の下端が広がると c・T がずれる。
- 床板は**平置き**（STL のまま）。パッドも平置き。

## 印刷後（底面の処理）— 必須

1. 床板・パッド・フードの**底面を平らなやすり**（#400 → #800、板の上でなでるように）で軽く均す。エレファントフットの出っ張りだけ取る。
2. **平らさの確認**: 平らな床（ガラス板など）に置き、**コピー用紙（約 0.1 mm）が縁のどこからも入らない**こと。入るなら、その辺を再度やすり掛け。
3. ノギスで厚さを測り、実測値を記録（設計値 T と 0.05 mm 以上ずれたら記録欄 notes に書く）。
4. 床板の前面（段差の面）は垂直のまま。**面取り・丸めをしない**。

## t = 0.05 mm を見る方法（板の代わりに薄板）

Engineering のシミュで、**0.05 mm だけが保持率が生き残った**組み合わせ（面取り 10/20° + 粗さ ±0.1 mm の 1 点、44〜59%、シード 1 つ、仮説は未検証）。**剛体で平らな 0.05 mm は 0% だった。** よって、実物でも「0.05 mm で入りやすくなるか」は**未確認**。PLA では作れない厚さなので、市販の薄板で見る。

- 用意するもの: **PET フィルム 0.05 mm**（市販の透明フィルム）または**ステンレスシム 0.05 mm**。長さ 60 mm × 幅 29.6 mm に切る。
- 貼り方: 詳しくは `T0p05_HOWTO.md`。要点は、**床に置いて後端だけテープで固定**（前面の縁の下にテープを入れない）。**前面の縁は切り口のまま垂直**（面取りしない、テープで縁を巻かない）。
- 面取り（10°/20°）を試すなら別のフィルム片に**手でやすり掛け**し、`notes` に「chamfer 10°」等と書く。粗さは別にいじらない。
- c を組み合わせるとき（c = 0.3 / 1.0）はパッドを足の帯の下に敷き、フィルムは c と別に床に置く（T = c + 0.05）。
