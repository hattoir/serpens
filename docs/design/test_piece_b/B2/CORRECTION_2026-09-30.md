## 訂正版の作り方

- **空間の床の板**（29.6×29.6、厚さ **T = c + t**）を、フードの壁の間の**床の上**に置く（下面が床に付く）。前面（段差の面）は空間の入口 x = 30.2（局所）。漏斗の床は床のまま。
- **パッド（c）は B2 のまま**（足の帯の下で、壁の下端を床から c にする）。c = 0 はパッドなし。
- 板の固定: 床に両面テープ（フードは板をまたいで動く）、またはフードの壁に軽く当てる。

## 厚さ T = c + t の組み合わせ（t = 0.1 / 0.2 / 0.5 / 1.0、c = 0 / 0.3 / 1.0）

| c \ t | 0.1 | 0.2 | 0.5 | 1.0 |
|---|---|---|---|---|
| 0 | 0.1（PET 0.1） | 0.2（PET 0.2） | 0.5（PLA 0.5） | 1.0（PLA 1.0） |
| 0.3 | 0.4（PET 0.2 + 0.2） | 0.5（PLA 0.5） | 0.8（PLA 0.5 + PET 0.2 + 0.1） | 1.3（PLA 1.0 + PET 0.2 + 0.1） |
| 1.0 | 1.1（PLA 1.0 + PET 0.1） | 1.2（PLA 1.0 + PET 0.2） | 1.5（PLA 1.5） | 2.0（PLA 2.0） |

- **シミュの既定 c = 0.1 と比べるときは、c = 0.1 を足す**（例: 「t = 0.1」は T = 0.2）。**B2 のパッドは 0.3 / 1.0 で 0.1 は無い**（c = 0.1 は 0.1 mm のテープ 1 枚を足の帯に貼る）。
- STL（PLA、平置き）: `print_corrected/B2c_FLOOR_PLATE_T0p5 | T1p0 | T1p5 | T2p0_PLA.stl`。PET 0.1 / 0.2、マスキングテープ用の外形（等倍）: `print_corrected/B2c_FLOOR_PLATE_template_1to1.svg`。
- 板の底は床（やすり掛けは不要）、上面は平らに。**前面（段差の面）は垂直に**（縁を丸めない。面取りをしない）。
