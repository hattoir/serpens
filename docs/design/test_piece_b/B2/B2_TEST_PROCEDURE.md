## 0. 1 回の試験の流れ（1 条件 = 約 3 分）

1. **床を決める**（フローリング / マット / 絨毯。優先度 A は c = 0・フローリングだけ）。試験の床を拭いて平らにする。
2. **条件を組む**: c（パッド 0 / 0.3 / 1.0）と t（床板 / PET / シム）を `B2_test_log_template_v2.csv` の行どおりに。**板は T = c + t**（`CORRECTION_2026-09-30.md` の表）。板は空間の中だけ、前面は口の面から 30.2 mm 奥。
3. **物を置く**: 1 円玉 / CR2032 / ビーズ φ8 / 立方体 10 mm を 1 個。口の面から前 50 mm、フードの中心線上。
4. **撮影を始める**: 真横 1 本 + 真上 1 本（スマホ 2 台か、1 台を交互）。ファイル名は `B2_c{c}_t{t}_{物}_{床}_{番号}_side|top.mp4`。**最初に条件の紙（c・t・物・床）を 2 秒映す**。
5. **フードを押す**: ロッド穴に φ8 の棒を差して、**10 mm/s 程度でゆっくり**（約 5 秒で 50 mm）真っ直ぐ物へ。位置ずれ 0（中心線上）で 3 回、次に **横へ 5 mm ずらして 3 回**（Engineering の位置ずれ 0・5 mm に合わせる）。
6. **結果を 4 分類**で記録: `enter`（入る）/ `return`（いったん入って戻る）/ `underrun`（下をくぐる）/ `pushed_away`（押されて逃げる）。それ以外は notes。
7. **各回の間に**: 物・フードの底・床の埃を確認。フードの底が汚れたら拭く。

## 2. 判断しないこと（記録だけ）

- 「合格」「安全」の語は使わない。**入った割合**（3 回中 n 回 + ずらし 3 回中 n 回）を書く。
- 予測（Engineering のシミュ）と違っても、原因を推測して条件を変えない。**違ったという記録がデータ**。
- 指を挟む恐れのある操作（板の縁・フィルム縁）は、フードを動かす手を縁から離す。**シムの縁は鋭い**。
