# t = 0.05 mm の貼り方（PET フィルム / ステンレスシム）

> **【先頭の注意】KNUCKLE DRUM 後も、まっすぐ比で約 20 倍（18〜24 倍）のすき間が残る。背板は現行 CAD では未解決のまま。5.7 N・0.25 N·m は暫定（SAFETY_UNVERIFIED）。安全・合格の語は使わない。**

## なぜ 0.05 mm か（正直に）

- Engineering のシミュ（`scoop_forms_2026-09-30.md` §12）で、t ≥ 0.002 mm の剛体・平らな段差は保持率 0%。**例外は 1 点だけ**: 面取り 10/20° + 粗さ ±0.1 mm + t = 0.05 mm（44〜59%、シード 1 つ、仮説は未検証）。
- 実物で同じことが起きるかは**未確認**。この手順は「起きるか見る」ための手順で、起きる前提ではない。PLA では 0.05 mm の板は作れない。

## 用意するもの

- PET フィルム 0.05 mm（透明フィルム）**または**ステンレスシム 0.05 mm。ノギス/マイクロメーターで**実測**する（表示厚と違うことがある）。
- 幅 29.6 mm × 長さ 100 mm 以上に切る（カッターと定規。切り口は垂直に、バリを取る）。
- マスキングテープ、平らな試験床。

## 貼り方（フードの空間に合わせる）

板は「フードの空間の中だけ」で、前面が口の面から 30.2 mm 奥（訂正版と同じ）。

1. 試験床にマスキングテープで、口の面の線と、そこから 30.2 mm 奥の線（フィルムの前縁）を引く。
2. フィルムの前縁をその線に合わせ、**後端（前縁から 70 mm 以上後ろ）だけ**テープで床に止める。**フードの通り道（足の帯・壁の下）にテープを入れない。**
3. フィルムを軽く引いてしわ・反りを取り、指でなでて浮きが無いか見る。前縁が**床から浮いていない**ことを、コピー用紙（約 0.1 mm）が前縁の下に入らないことで確認する。
4. 前縁は**切り口のまま垂直**。縁を丸めない・テープで巻かない。
5. フードを載せ、壁の間にフィルムが入っていることを確認する（フィルムは壁の内側 29.6 mm で、壁と擦れない）。

## 組み合わせ

| 条件 | 用意 |
|---|---|
| c = 0, t = 0.05 | フィルムのみ（パッドなし） |
| c = 0.3, t = 0.05 | パッド 0.3 mm + フィルム（T = 0.35） |
| c = 1.0, t = 0.05 | パッド 1.0 mm + フィルム（T = 1.05） |
| 面取り 10° / 20° | 別のフィルム片の前縁を**やすりで手で面取り**（角度は分度器で確認）。notes に角度を書く |

- シミュの既定 c = 0.1 と比べるときは 0.1 mm のテープを足の帯に貼る（CORRECTION と同じ）。
- 粗さ ±0.1 mm は**意図的にいじらない**（実物の床・フィルムの自然な状態を記録する）。

## 注意

- フィルム・シムの縁は鋭い。指を切らないよう、フードを動かす手を縁から離す。シムは特に。
- 絨毯の毛足は 0.05 mm より大きい。**絨毯での結果は参考**として notes に「参考」と書く。
- 結果が悪くても（保持されなくても）、調整（縁の追加加工・粗さの追加）は入れずにそのまま記録する。
