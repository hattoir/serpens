# KNUCKLE 試験片の確認手順（印刷したあとにやること）— 2026-10-01

> **先頭の注意**: KNUCKLE DRUM 後も、まっすぐ比で約 20 倍（18〜24 倍）のすき間が残る。背板は現行 CAD では未解決のまま。5.7 N・0.25 N·m は暫定（SAFETY_UNVERIFIED）。安全・合格の語は使わない。
> この試験片は**胴の層（z 8〜76）の 1 関節分**だけ。背板の層（約 1020 mm³/姿勢）・ケーブル・内部・公差は入っていない。**手で確かめるのは外形とすき間の感触まで**で、指の挟み込みの安全を確かめるものではない（Engineering の試験計画と別）。

## 何がわかるか

1. **KNUCKLE DRUM の形が実物でも成り立つか**: 関節を曲げても、玉の脇の円柱と椀のすき間が**約 4 mm のまま**か（CAD では R46 / R34 で 0〜±50° の間 一定。印刷の公差・反りで崩れないか）。
2. **5〜12 mm のすき間が残っていないか**: 探針 d5.0 が入る場所と d12.0 が入らない場所の間に、「5 は入るが 12 は入らない」すき間が無いか（CAD の計算は 0 mm³ だが、実物の角・面取りの V での確認）。
3. **組み立てと動き**: 玉が板の溝の端（約 ±52°）で止まるか、指針が目盛りに合うか。
4. **見た目**: 関節に「膝」のような円柱の出っ張りができる。**かわいいか・変でないか**（User の判断）。

## 手順

1. 組み立て（`README.md`）: 板の突起に椀 B を置き、玉 A の中心穴を板の軸に差す。
2. 玉を **0° / ±25° / ±50°** にして、各角度で以下を記録する。
   - **探針 d5.0（`GAUGE`）を、椀と玉のすき間・面取りの V に当てる**: 入る場所を全部メモ（上・中・下の 3 か所を目安に）。
   - **探針 d12.0**: 入るか。
   - **5〜12 mm の帯**: d5 は入り d12 は入らない場所 = 要注意。場所を鉛筆と写真で記録。
   - 円柱と椀のすき間を**すきまゲージ / ノギス / 紙の厚み（0.1 mm）**で測る（設計 4 mm。±0.5 mm を目安に記録）。
3. **玉を端まで回す**: ±52° 付近で止まるか、無理に回さない。引っかかる・擦れる場所をメモ。
4. 写真: 真横・真上・すき間のアップ（角度ごと）。ファイル名 `KNUCKLE_R46_a+25_top.jpg` のように。
5. **R34（J2 相当）と R46（J3〜J5 相当）の両方**で行う。R34 の椀 B は STL に開いた辺 18 か所がある（スライサの修復で直る見込み。直らず印刷が崩れた箇所があれば記録）。

## 記録

`KNUCKLE_TEST_LOG_template.csv` に 1 行ずつ。列: piece（R46/R34）、angle_deg、location（上/中/下）、d5_enters、d12_enters、gap_mm、gap_5_to_12（y/n）、note。**合格・不合格の語は使わない**（入った / 入らなかった、測った値だけ）。結果は `ai-shared/HARDWARE_TODO.md` の **HT-014** に貼る（または `ai-shared/knuckle_results/` に置く）。

## 記録後に AI がやること

- Design: 実測のすき間を CAD_CONCEPT の値と比べ、ずれる場所（公差・反り）を形の余裕へ反映。5〜12 mm の帯が見つかったら、その場所を Fusion で直す案。
- Engineering: 実物で見つかった帯があれば、挟み込みの許容トルクの前提（接触半径）を見直す。
- **背板の層が残っていること（約 20 倍の大部分）は、この試験では確かめられない**（別の試験片が要る）。
