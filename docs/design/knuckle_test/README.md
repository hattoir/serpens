> **先頭の注意**: KNUCKLE DRUM を入れても、まっすぐに比べ曲げた姿勢では約 20 倍（18〜24 倍）の体積のすき間が残る（背板の層 約 1020 mm³/姿勢は未解決、J1 ピッチは動作範囲の回答待ち）。**この試験片は胴の層（z 8〜76）の円柱肩だけを確かめるもので、背板の層は含まない。**

## 組み立て

1. 板の位置決め突起（d6）に椀 B の穴（d6.4）を差して置く（必要なら接着）。
2. 玉 A の中心穴（d8.6）を板の軸（d8）に差す。玉の下の突起（d3.6）が板の溝（幅 4.4）に入る。玉は溝の端（約 ±52°）で止まる（**機構のストッパー 52° に合わせた**）。
3. 玉の後ろの指針を、板の目盛り（0・±25・±50°）に合わせる。

## 確認のしかた

- 玉を 0・±25・±50° にして、探針 d5.0 が **入らない**、d12.0 も入らない、その間（隙間が 5〜12 mm のもの）が無いかを、椀と玉のすき間・面取りの V に当てて見る。
- Python 検査（STL、0.5 mm）では、A と B・板の干渉は **0 mm³**（0・±30・±50・±52°、両種類）。

## 注意・限界

- **[A] の仮置き**: 中心穴・軸・突起・溝・指針・目盛り・板の寸法。試験用の治具で、ロボットの部品ではない。
- R34 の椀 B の STL に **開いた辺 18 か所**（0.001 mm 丸めでの検査）。スライサの「修復」で直る見込みだが、確認していない。
- 試験片は胴の層（z 8〜76）。背板の層・ケーブル・内部・公差は入っていない。人の手で確かめるのは **外形とすき間の感触** まで。
- Fusion: `KNUCKLE TEST R46 / R34 A1 print …`（組立の位置）と `… PRINT ORIENTATION …`（印刷の向き、非表示）。名前に [CAD] / [A] / [C] を書いた。
