# P0 — B2 の印刷物（この 7 ファイルを印刷する）

> **先頭の注意**: KNUCKLE DRUM 後も、まっすぐ比で約 20 倍（18〜24 倍）のすき間が残る。背板は現行 CAD では未解決のまま。5.7 N・0.25 N·m は暫定（SAFETY_UNVERIFIED）。安全・合格の語は使わない。これは手で観察する試験片で、ロボットの部品ではない。

## 設定（Bambu A1）

- フィラメント **Generic PLA**、積層 **0.20 mm 標準**、プレート **スムース PEI**。
- **エレファントフット補正 0.1〜0.2 mm**（床板の底とフードの壁の下端が広がると c・T がずれる）。
- フード: 壁 3 周、インフィル 15%、サポートなし。板・パッドは平置き。

## 印刷したあと

1. **底面をやすり掛け**（#400 → #800、平らな板の上で軽く）。エレファントフットの出っ張りだけ取る。
2. **平らさの確認**: 平らな面（ガラス板など）に置き、**コピー用紙（約 0.1 mm）が縁のどこからも入らない**こと。入るならその辺を再度やすり掛け。
3. ノギスで厚さを測って記録（設計値と 0.05 mm 以上ずれたら記録する）。床板の前面（段差の面）は**垂直のまま**（面取り・丸めをしない）。

## 印刷しないもの

旧 `B2_STEP_SHEET_t0p5 / t1p0`（位置と c の基準が誤り）、旧 B1。
