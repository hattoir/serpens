## 0. 結論

1. **窓 θ_E −4〜+3° = CAD +4〜−3°**。窓（フードの尾、r 45.5〜48.5）は、**パッド t = 3 mm で φ 30.5〜48.5°（弧長 14.8 mm）**、**t = 6 mm で φ 26.9〜52.1°（20.8 mm）**、幅 3.6 mm、|y| = ±18。ピンは首の芯から半径方向に**鋼ダウエル φ3**（r 38〜48.5、埋め込み 7 + 露出 3.5）。
2. **危険体積（θ_E、Design の計算）**: **+4°（頭を上げる）= 151 mm³**、**−4°（頭を下げる）= 覆いなし 319 mm³ / 覆いあり 23 mm³（案 A）**。**Engineering の補間（+4° 164、−4° 覆いなし 205 / 覆いあり 13）とは、+4° は −8% で近く、−4° は覆いなしが +56%（205 → 319）、覆いありが +77%（13 → 23）で、補間は下側を過小に見ていた**。
3. **範囲 [−4, +3] の最悪**: 覆いなしは **−4° の 319 mm³**（覆いありは +3° の 44 mm³ で最悪 = 覆いなし / あり = **7.3 倍**。下側だけで見ると 319 / 23 = 14 倍。前回の「約 5 倍」は補間による過小）。

## 5. 訂正と選択（ENTRY-E-0014 を受けて、2026-09-30 夜）

- **訂正**: 上の「TPU は E 3 MPa 級（Shore 60A 前後）が要る」は**誤り**。Design のパッド断面 3.6 × 2.0 = 7.2 mm² では E 3 MPa は底付きする（ひずみ 0.77 / 0.55 > 0.4）。**Engineering の 2 案から選ぶ**（どちらも鋼ダウエル φ3 が前提。120°/s・減速なしの SF p05）:
  - **P1**: 95A 級（E ≈ 20〜30 MPa）、厚さ 3 mm、窓 14.8 mm（φ 30.51〜48.49°）、SF 2.5〜2.9。**Design の既定 = P1**（窓の壁 2 mm の剛性を守る）。
  - **P2**: E ≈ 10 MPa 級（85A 前後、ASSUMED）、厚さ 4〜6 mm、窓 最大 20.8 mm（t = 6: φ 26.86〜52.14°）、SF 4.0〜4.6。衝撃を小さくしたい場合。
  - **選ぶ基準は HT-008 で測る E**（Shore ではない）。E が ±50% ずれても P1 / P2 の SF は上の範囲。
- **STL は t = 3 / t = 6 の両方を残した**: `j1_cover_v2/J1v2_WINDOW_V2_*.stl` + `J1v2_TPU_PAD_*`（t = 3）、`J1v2_WINDOW_T6_*` + `J1v2_PAD_T6_*`（t = 6）。Fusion `J1 STOPPER v2 + COVER VARIANTS STUDY 02` に両方。HT-008 の E を見て切り替える。**窓・穴はまだ切らない**（HT-001 の後）。
- **窓の端面の支圧**: 8〜12 MPa（PLA 圧縮 20〜30 MPa の仮定で SF 1.7〜3.6、83 N で余裕小。未検査 = HT-009）。**変形が出たら金属のスリーブ**（φ3 の黄銅パイプ等）を窓の端に入れる（Design の案。形は HT-009 の結果を見て起こす）。パッドは窓の端面へ**均一に接着**（片当たりは局所の応力が上がる）。ダウエルの圧入の引き抜き ≥ 約 120 N（Engineering の提案、HT-009）。
