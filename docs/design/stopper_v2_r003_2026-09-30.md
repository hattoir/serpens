# R-003 への回答 — ストッパー v2（窓 θ_E −4〜+3°、鋼ダウエル φ3 + TPU パッド）と ±4° の危険体積

> **先頭の注意**: KNUCKLE DRUM 後も、まっすぐ比で約 20 倍（18〜24 倍）のすき間が残る。背板は現行 CAD では未解決のまま。5.7 N・0.25 N·m は暫定（SAFETY_UNVERIFIED）。安全・合格の語は使わない。
> 数値の出典: 寸法・危険体積 = **CAD_CONCEPT / KINEMATIC_SIM**（Design の計算: 外形 STL、0.5 mm ボクセル、幅 5〜12.5 mm・深さ 8 mm 以上の届くすき間、範囲 x −250〜−110・|y| ≤ 60）。荷重・材質 = **Engineering の prior（ENTRY-E-0011）を引用**。**Design の見積もり（Engineering 未検証）**。実機の符号は **HT-001 の後**に窓を切る。
> **符号**: 姿勢ラベルは θ_E（+ = 頭を上げる）で書く。CAD の姿勢変換は θ_CAD = −θ_E（+ = 頭を下げる。`j1_sign_correction_2026-09-30.md`）。

## 0. 結論

1. **窓 θ_E −4〜+3° = CAD +4〜−3°**。窓（フードの尾、r 45.5〜48.5）は、**パッド t = 3 mm で φ 30.5〜48.5°（弧長 14.8 mm）**、**t = 6 mm で φ 26.9〜52.1°（20.8 mm）**、幅 3.6 mm、|y| = ±18。ピンは首の芯から半径方向に**鋼ダウエル φ3**（r 38〜48.5、埋め込み 7 + 露出 3.5）。
2. **危険体積（θ_E、Design の計算）**: **+4°（頭を上げる）= 151 mm³**、**−4°（頭を下げる）= 覆いなし 319 mm³ / 覆いあり 23 mm³（案 A）**。**Engineering の補間（+4° 164、−4° 覆いなし 205 / 覆いあり 13）とは、+4° は −8% で近く、−4° は覆いなしが +56%（205 → 319）、覆いありが +77%（13 → 23）で、補間は下側を過小に見ていた**。
3. **範囲 [−4, +3] の最悪**: 覆いなしは **−4° の 319 mm³**（覆いありは +3° の 44 mm³ で最悪 = 覆いなし / あり = **7.3 倍**。下側だけで見ると 319 / 23 = 14 倍。前回の「約 5 倍」は補間による過小）。
