## 0. 結論（3 行）

1. **上の輪の覆い（襟の前縁を同心の殻で 8° 前へ延ばす、r 49.5〜51.1、厚さ 1.6、|y| ≤ 30、870 mm³）は、頭を下げる側のすき間を大きく減らす**: **Engineering の −5°（範囲の端 = CAD +5°）で 401 → 29 mm³、CAD +10°（範囲外）で 2062 → 234 mm³**。全姿勢で頭との重なり 0。
2. **下の後ろのくさび（頭を上げる側）は、首側の詰め物でも頭側の詰め物でも埋まらない**（頭がその領域を他の姿勢で通るため）。**Engineering の +5° = 601（詰め物で 417〜419）、+10° = 1562（詰め物で 1551）のまま**。形で解決できない → **範囲を狭める（+3° = 44 mm³）か、覆いを動く部品にする**の判断が要る。
3. **ストッパー**は、首の芯から半径方向に出るピン（φ3、|y| 18）と、フード（r 46〜48）に切る弧状の窓（工具体）。窓は 2 種: **全範囲（Engineering −5〜+10°）**と **変種 B（−5〜+3°、下のくさびで制限）**。**荷重の受け方・強度は未検査**。

## 3. 人・Engineering が決めること
