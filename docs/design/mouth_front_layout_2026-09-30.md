## 3. 「J1 = 0° で口の下端が床と平行」の作り方

- **足の帯の底と、スキッドの底を、頭の座標で同一の水平面の上に置く**: スキッドの底 = 床（z 0）、足の帯の底 = z c₀（シミュの既定 0.1 mm）。**スキッドが c₀ だけ下へ出る**ので、頭はスキッドで床に乗り、フードは床から c₀ 浮く。
- J1 = 0° は、首の芯が胴と平行な姿勢（CAD の中立）。頭の座標がこの姿勢の水平に対して作ってあれば、足の帯の底は自動で床と平行。**公差**: 4 つのスキッドの底の高さの差 0.05 mm は、支持の間隔 62 mm で傾き 0.05° = 口の前縁で 0.05 mm（c₀ の半分）→ **スキッドの底をやすり掛けで同一面に**（B2 の README と同じ手順）。
- **頭は J1 で床に押し付けない**: 頭の高さはスキッドが決める。J1 は 0° を指令し、**トルクを小さく（柔らかく）**して、床の凸凹・胴の傾きに頭がスキッドで追従する（Engineering の確認）。

## 4. ENTRY-D-0006 の確認事項への回答

### (1) c の基準面（Engineering のシミュの定義と揃える）

**シミュのコード**（`simulation/scoop/forms/common.py` の `hood()`、`passive.py`、`config/scoop.yaml`。`agent/engineering-scoop`、読み出しのみ）:

- 壁の下端 z = **c（床から）**。板が無いとき、空間の床 = 床（z 0）。
- 板があるとき（`plate` = t）: **板の geom は z = c 〜 c + t**（下面が床から c、上面が c + t）、**壁の下端は c のまま（床から）**。空間の床の高さ zb = c + t。板は**空間（x 0〜30、\|y\| ≤ 15）の中だけ**で、**漏斗（口の前 30 mm）には板が無い**（漏斗の床は床のまま）。
- **したがって: c は床から測る。板の上面からではない。物が見る段差 = 床から板の上面まで = c + t。**（既定 c = 0.1 のとき、t = 0.1 の段差は 0.2 mm。Engineering の「t = 0.1 で 0 %」は、実質 c + t = 0.2 mm の段差。）

**B2 への影響（Design の誤り）**: B2 は (i) 板を**足の帯の下・口の面から敷く**、(ii) c を**板の上面から**とした。シミュは (i) 板は**空間の中だけ、前面は空間の入口（口の面から 30 mm 奥）**、(ii) c は**床から**。→ **訂正版**（`CORRECTION_2026-09-30.md`）: **空間の床の板（29.6×29.6、厚さ T = c + t）を、フードの壁の間の床に置く**（物が見る段差は同じ）。パッド（c）は今のまま。**B2 のフード本体・パッドは変更なし**（板だけが訂正）。

### (2) ToF（下向き）を空洞の外へ移す案

- **可**。空洞の外（奥の壁の後ろ）の **x −172〜−165、\|y\| ≤ 7、z 7〜9** は、空洞・掃引幅・下の後ろの埋め物（x ≥ −162、z ≥ 9.6）のいずれとも重ならない（重なり 0 mm³）。後ろのスキッド 2 つの間に置ける。
- **高さ測定の要件（Design から Engineering へ）**: (a) **この位置の ToF は床から 7〜9 mm**。一般的な単点 ToF の最短測定距離は数 cm のことが多く、**この高さでは床が測れない可能性**がある → **部品の最短測定距離を確認**（Design は型番を知らない）。(b) **c・t（0.1 mm 単位）の確認には ToF は使えない**（分解能が 1 mm 級）。**口の高さは J1 の角度と、スキッドの底の高さで決まる**（口の前縁は J1 1° で 0.95 mm）。(c) この位置の ToF は**口から 64 mm 後ろの床**を見る。**前方の段差・崖の検出には使えない**（前方は別のセンサー）。(d) 空間の中の物の有無は、屋根の下面からの下向き（屋根から床 15 mm）も候補だが、(a) と同じ最短距離の問題がある。

### (3) J1 の作業窓と機械ストッパー角

**口の下端の高さ**（J1 軸 (−181.8, z 32.4) まわりの回転、床から 0.1 mm 浮いた足の帯が J1 = 0° で水平、+ = 頭を上げる）。単位 mm、床からの高さ:

| J1 | 口の前縁 x −236 | 空間の入口 x −206 | 奥の壁 x −176 |
|---|---|---|---|
| −2° | **−1.77（床の下）** | **−0.72（床の下）** | 0.32 |
| −1° | **−0.84（床の下）** | −0.32（床の下） | 0.21 |
| −0.5° | −0.37（床の下） | −0.11（床の下） | 0.15 |
| −0.1° | 0.0（接触） | 0.06 | 0.11 |
| 0° | 0.10 | 0.10 | 0.10 |
| +0.5° | 0.57 | 0.31 | 0.05 |
| **+0.95°** | **1.00** | 0.51 | 0.01 |
| +2° | 2.01 | 0.96 | −0.08 |

- **マイナス側**: 口の前縁は**床にめり込む**（c₀ = 0.1 で **−0.106°**、c₀ = 0.3 で −0.32°、c₀ = 1.0 で −1.06°）。**頭を床に押し付ける**ことになり、前縁の底（面取り 0.3）が床に食い込む。**床は動かないので、頭が前縁を軸に回り、奥が浮く**（−1° で奥の壁の下 1.15 mm、−2° で 2.2 mm: 1 円玉（厚み 1.5）が奥の下をくぐりうる）。**「壁の下端が床に触れて段差になる」恐れは、ある**（前縁の接触は、床の凹凸で引っ掛かる縁になる。絨毯は未対応）。
- **プラス側**: c の実効 = c₀ + 0.95 mm/° × θ。**c ≤ 1.0 を守るのは +0.95°（c₀ = 0.1）、+0.74°（c₀ = 0.3）まで**。
- **作業窓**: すき間の面（≤ 10 mm³）は **−2〜+1°**、取り込みの面（c ≤ 1.0、前縁が床に触れない）は **−0.1〜+0.9°**（c₀ = 0.1）。**両方を満たす窓 = −0.1〜+0.9°**（**J1 の角度の分解能 0.088°（12 ビット 4096/回転の場合。Engineering の確認）の約 1 ステップの余裕しかない**）。→ **窓を J1 の角度で守るのは難しい。スキッドで頭の高さを決め、J1 は 0° 指令で柔らかく** が現実的（§3）。
- **機械ストッパー角**: 取り込み中の窓は J1 で**守れない**ので、ストッパーは窓のためでなく**範囲の端の保護**: **−5° / +10°（Engineering の暫定）のまま**（首の芯の扇の端面）。作業中はソフトの制限を **−1°〜+1°**（Engineering の制御）にし、スキッドで頭が床に乗る。**ハード端の −5° / +10° ではすき間が 601 / 2062 mm³ 残る**（`j1_pitch_2026-09-30.md`）。

### (4) 頭の殻の空洞の強度（PLA、E = 3.5 GPa [R]、梁の概算 [C]）

- フードは **PLA の別部品（頭のあごの空洞に接着 / ねじ止め）** とする案。**壁 1.6 mm・屋根 1.6 mm・足の帯 3.6×4 mm [A]**（最小 1.2 以上）。
- **壁**（高さ 15、長さ 34、上端固定・下端自由の片持ち）: **1 N の横向きの力（全体）で下端が 0.028 mm** 動く。**c₀ = 0.1 mm の 1/4 未満**。物（1 円玉 約 2 g）を押す力は 0.01 N 程度なので**壁の変形は無視できる**。
- **口の前の縁（屋根の漏斗の前、幅 60）**: 中央に 0.5 N で **0.063 mm** たわむ（単純支持の梁）。**c₀ と同程度**なので、**指で押すとすき間が変わる**。ただし取り込みの力（0.01〜0.1 N）では 0.006 mm 以下。
- **足の帯**（頭の重さ 2 N を 3.6×190 mm で受けると 0.003 MPa）: 圧縮は無視できる。**問題は強度でなく平らさ**（底面の平面度 ±0.05 を、やすり掛けで作る）。
- **あごの残り壁**: フードを入れるあごの空洞（25 cm³）の周りに **2 mm 以上** を残す案 [A]（あごの実体が中実か殻かは未確認）。**未検証**: あごの外殻の強度、ねじ穴、口の前縁の接着面。
